# Third-party components

## Three.js

In Pocket Atelier, the mobile layout uses the embedded Canvas renderer without requesting Three.js. The desktop startup path dynamically requests Three.js version 0.160.0 (r160), using its global UMD distribution, from one of these URLs:

```text
https://cdnjs.cloudflare.com/ajax/libs/three.js/0.160.0/three.min.js
https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js
```

Three.js is licensed under the MIT License. Copyright belongs to the Three.js authors. The engine itself is **not included** in this standard source archive or HTML. When using the optional vendored/embedded build, obtain and preserve the corresponding license from the official version:

```text
https://github.com/mrdoob/three.js/blob/r160/LICENSE
https://threejs.org/manual/en/installation.html
```

## Artwork / historical Atelier edition (v0.4)

The two approved concept images from this conversation are included in
`assets/references/`. Version 0.4 derives independent painted architectural
cutouts, portrait plates and frame masks from them; `assets/atelier/manifest.json`
records the source crop, mask and processing method. Sword illustrations use a
masked painted blade plus deterministic grip/material compositing. They are not
new high-resolution, independently painted illustrations for every card.

Entities not represented in the concepts retain the original programmatic
illustrations from `src/tavern-art.js` and their pre-rendered WebP files.
Material textures are generated by `tools/make_materials.py` and
`tools/build_atelier_assets.py`. The source archive does not include the web
reference screenshots from earlier art-direction work or original game audio.
No font files are included; the interface uses locally installed system fonts.
Audio is synthesized with Web Audio.

## Development-only tools

Node.js, Python, Chromium and Playwright are not redistributed. They are only used for development or optional testing. Refer to their own licenses if distributing a development environment containing them.

Artwork build helpers use Pillow, NumPy, OpenCV and CairoSVG at development time only. No engine, browser, font or development dependency binaries are bundled.


## Current artwork / Wind Borne (v0.7)

All 56 active card images use the eight approved anime atlases introduced in v0.6; no active card illustration falls back to the historical procedural portraits. See `assets/anime/manifest.json` for the extraction sources and mappings. Six non-card relic images remain inherited.

The approved environment images are provided in `assets/references/world/`. Four building layers and the clear skyline are derived from the approved village painting. The clean board, paper / wood material plates and leaf emblem are authored UI / surface assets. Extraction polygons and exact source/output SHA-256 values are recorded in `assets/windborne/manifest.json`. No original Hearthstone game media, downloaded reference photos, recordings, font files or engine binaries are redistributed in this edition. This source archive makes no assertion of a separate commercial-art license for generated concepts beyond their documented conversation provenance.
