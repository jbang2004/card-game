# 艾莉娅战场模型

`alia.glb` 是星焰法师 `mage` 的专用表现素材。英雄的血量、护甲、技能、目标选择及规则仍由现有 DOM 和规则层负责。

## 来源

- 身份参考：当前英雄的 `portraitId=oracle` 银发星界法师原画。
- 模型参考图：用户授权使用 Image Gen 制作的全身 A 姿势图，保留银发、蓝披风、象牙白前襟与金色星饰。
- Tripo Studio 项目：`18c0765f-24db-4332-98d2-4f3691f662bd`。
- 原始生成：v3.1，几何与贴图；重拓扑后 18,292 个三角面，1 个网格、1 个材质。
- 骨骼任务：`7c2c27d2-e621-4c2f-9263-9d74f7a3c19e`，65 根 Mixamo 骨骼。
- 积分：生成 55、重拓扑 35、绑定 20，共 110。

原始 GLB 与参考图保存在本地制作记录 `output/hero-3d-20260920/source/`。仓库不保存临时签名下载地址、登录信息或 API 密钥。

## 处理约定

使用 `tools/decode-hero-meshopt.mjs` 解压几何，`tools/optimize-hero-textures.py` 将颜色贴图缩至 2K、法线及金属/粗糙度贴图缩至 1K。模型内嵌全部纹理，运行时不访问 Tripo。普通游戏构建只读取最终 GLB，不需要 Blender、Pillow 或外部服务。

Tripo 预设待机、施法、身体受击动作已在工作台预览，但其动画导出未取得可读取的文件；最终战场动作由本项目基于已导出的骨骼制作，不能标记为 Tripo 预设动画。

制作与验收详情见本地 `output/hero-3d-20260920/production.md` 及 `qa/`。

## 动作再制作与检查

`node tools/animate-mage-hero.mjs art/models/alia.glb /tmp/alia-review.glb` 在现有模型上重新生成项目原创动作；源边界写入 GLB 元数据，重复运行不会累积旧动画数据。动作 v3 为完整骨骼编舞：4.4 秒循环战斗待机保持站直与轻微重心差，左手叉腰、右手自然垂落，胸肩呼吸、手腕与头部调整使用不同节奏；1.6 秒施法由右肘带动前臂上扬，0.55 秒单掌向战场推出魔法，左手始终稳定在腰侧；0.78 秒受击含上身后仰、轻微缓冲与收势。每段驱动 26 根骨骼，加 Hips 平移；双腿解析 IK 固定脚部，角色根节点不移动。

GLB 的 `asset.extras.emberfallMotion` 记录版本、施法时长和释放点；`cast.extras` 记录相位区间。工具在输出文件旁写入 `.motion.json`，含采样关节位置、膝角、腰侧手锚点误差、运动范围和脚部漂移量，方便复核。v3 多视角相位图、实模循环预览、确定性重生成结果和定量报告位于 `output/hero-pose-v3-20260920/`。

`python3 tools/validate-hero-model.py art/models/alia.glb` 检查文件自包含、四肢骨骼链、顶点权重/关节索引、动画时间与四元数。浏览器专项位于 `tests/e2e/hero-model.spec.cjs`。

## 布料权重修复

Tripo 自动绑定把部分低处袍摆赋给手指，导致抬手时前袍翻起。`tools/repair-mage-cloth-weights.mjs` 针对此模型的下垂布料/中央袍区修复2,897个顶点，保护手骨4cm内的42个候选顶点；把误分给手臂/手指的权重转回原身体/腿部骨骼，维持权重和，不改网格、材质与骨架。修复后重新制作动画，并人工对照待机/施法峰值确认前袍稳定。
