# 生成/透明输出：每次使用前核验

仅在确实需要生成或提取位图时读取。不要因任务是“复刻”就自动生成图片。

## 稳定的检查方法

- 先查看当前工具的实际参数和相关技能。工具名、用户称呼或提示词里的模型名不证明实际运行的模型版本。
- 涉及最新能力时核验官方文档，记录日期、具体模型/快照、工具暴露的参数和来源链接。API 支持不代表当前内置工具能设置同一参数。
- 若当前模型/API 支持透明背景，使用其明确的透明参数及支持 Alpha 的格式。不要把“输出透明 PNG”这句话视为参数已经生效。
- 解码检查通道、透明/半透明像素和边角；在深浅背景及实际场景上看边缘。PNG 格式不等于包含 Alpha；棋盘格可能已经烘焙进 RGB。
- 从单一合成图不能唯一恢复原始 Alpha 和光晕颜色。重建边缘需如实记录；程序化修图须符合当前工具约束与已有授权，不因历史案例授权自动获得新任务授权。
- 同一素材保留原始生成结果、提示词、加工方法和最终消费路径。不要覆盖来源或把原生透明与后处理透明混为一谈。
