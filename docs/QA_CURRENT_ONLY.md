# 当前版本单路径验收 · 2026-09-08

用户确认游戏仍在测试期、没有旧对局需要保留。旧对局兼容要求已从 AGENTS.md 和当前设计文档中撤销。

## 实现

- 对局只接受 version 2。旧 version 1、ruleset、legacyDeck 和 tempAtk 状态拒绝恢复；没有旧版本执行分支。
- 触发能力与发现卡池始终执行当前规则；开局、重试和战役整备始终检查英雄职业。
- 每个随从初始化 modifiers；临时攻击增益只从其中合计，到期扣除并移除，不再维护第二份 tempAtk。
- 命名卡组仅接受 version 2 集合，不迁移旧数组，不接受无英雄关联的旧记录。读取失败时可明确重建测试卡组收藏；写入失败不报告成功。
- 四个既有存储键名沿用，仅作为存储位置，不意味着支持旧格式；设置和世界偏好不受影响。
- 删除两个旧版本测试 fixture。当前 save-current.json 由明确的当前对局局面构成，用于规则测试和浏览器跨刷新恢复。所有 62 张卡牌还逐张检查确定性结算与状态恢复，具体效果由已有独立规则用例验证。

## 重点检查

旧对局拒绝且不覆盖运行状态；临时/永久增益混合后保存恢复与准确到期；没有版本开关的触发与职业发现；跨职业旧参数不可绕过校验；旧卡组重建后两套命名牌组分别保存和开局；当前对局两次实际浏览器刷新恢复；旧测试存档失效提示与新 version 2 开局。

桌面和手机横竖屏检查属于本机 Chromium 与触屏模拟，不代表实体手机。未发布线上。
