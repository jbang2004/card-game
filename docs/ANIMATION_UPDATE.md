## 人物动态边界

`presentation/portraits.js` 使用共享时钟和按实体身份保留的相位；DOM 重建不会把待机动画归零。画布仅覆盖插画窗口，冻结时暂停该角色待机，其他角色不会因一次施法全体停顿，离屏不绘制。触屏最多 6、桌面最多 12 张同时绘制，跟随显示刷新绘制，画布尺寸有上限。低画质/减少动态/素材加载失败时保留各卡原静态图。

素材由内置 image_gen 以原卡为参考生成分层图与遮罩，再通过既有 Playwright 浏览器进行确定性打包。9 张 WebP 合计约 0.37 MB；原 56 张 WebP 没有替换。它们属于派生图层样板，不是原画逐像素拆分，也没有实现眨眼、表情、头部网格变形或完整骨骼（第二阶段新增独立头部图层旋转，见下）。来源、完整提示词及打包命令见 `assets/motion/PROMPTS.md`。

## 流畅度与拖尾修正

根据实际演示反馈，取消手牌循环扫光，增强人物主体侧倾和凤凰双翼动作。原先每帧比较 33.33ms 阈值会在 60Hz 下不均匀跳帧；现使用显示帧时钟，布局测量交给 ResizeObserver / IntersectionObserver，不再按变换后的尺寸反复重建画布。相同实体重绘复用画布，避免动态与原静态图之间闪切。

冻结命中改为短促冰屑与 240ms 局部结冰边框，移除长冰雾/法阵和过长弹道尾迹；去除与战斗动画争用的 CSS filter/transform 过渡。Chromium 同场景观测由约 22fps（中位帧距 49.9ms）改善到约 60fps（中位 16.7ms、P95 17.5ms）；冻结提示后 450ms 的 Canvas 残留项由 40 降到 0。这是本机浏览器观测，不代表实体手机性能。

新增回归验证绘制与显示帧同步、画布身份复用、稳定状态不重分配尺寸，以及冻结后没有残留粒子/滤镜过渡。演示页增加“放大观察人物”，显示游戏画布本身。人物仍是分层主体/翅膀动态，不包含眨眼、独立表情或完整面部绑定。

流畅度修正后的完整复验：`npm run test:release` 通过，66 项 Node 测试、34 项 Playwright 用例。放大演示独立验证了大尺寸画布加载与关闭后的节点清理。
