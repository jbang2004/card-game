# 攻击、法术与传说演出 · 2026-09-08

本文件保留首次演出迭代的验证数据。后续无损 WebP 转换、13 张运行素材、加载隔离与最新体积见 [资源清理记录](MEDIA_CLEANUP.md)。

本轮延续 [音画反馈优化](AUDIO_FEEDBACK.md)，把 62 张卡牌及衍生物显式映射到攻击、施法和登场表现。改动已接入实际对局与演武场，使用原有 Canvas/DOM、因果事件与只读状态接口。目标是提升动作含义、命中反馈与层次；不把这次浏览器表现迭代描述为达到炉石完整商业制作水准。

## 实际变化

| 场景 | 表现与时序 |
|---|---|
| 刀剑 / 利爪 / 重击 | 方向性纹理刀光、三道爪痕、地面裂纹与碎屑；使用已有 220 ms 接触拍，命中后迅速显现，随伤害调整强度 |
| 弓箭 / 投矛 / 能量弹 / 龙息 | 保持施放者在原位；箭形弹道、加重投射体、发光弹芯与流动火焰束分别抵达实际目标；远程单位不再套用近战冲撞 |
| 陨火术 / 烈焰风暴 | 单体与范围落点预告；加速陨火与渐细火焰尾迹；命中拍触发动画爆破、烟尘和余烬。范围弹道起飞错开，抵达与同一批伤害同步 |
| 冰封领域 / 冰霜箭 | 多目标结晶扩散或定向冰晶弹道；冻结规则仍在结果拍生效，状态稳定后不持续喷冰粒子 |
| 暗影湮灭 / 沉默 / 变形 | 目标处的暗色收束漩涡与符文；消灭仍由独立死亡事件处理，不伪造伤害数字 |
| 治疗 / 护盾 / 召唤 / 抽取 | 祝福光柱、护盾光纹、自然法阵与星轨采用不同施法形式，结果仍由原有治疗、状态、召唤、抽牌拍揭示 |
| 日曜王冠 / 星界之门 / 灰烬龙翼 / 冰霜王座 | 四张传说牌 620 ms 起手、具名提示、各自登场；战吼从实际落地单位发向受影响目标，保留既有卡牌飞行与落地音 |
| 首领觉醒 | 原有阶段文案与首领位置结合对应的龙翼、冰霜、星门或光冠演出；不额外制造攻击或伤害 |
| 演武场 | 保留七种元素，新增 14 项类型选择；使用实战同一渲染器。皮革/胡桃木/古金配色统一，特效限制在预览区域内，支持键盘重播和退出 |

法术起手时间按语义分布在 320–800 ms，普通随从 300 ms，传说随从 620 ms，英雄技能 420 ms。总事件链仍遵循既有 6.5 秒预算，所有弹道使用缩放后的事件时长。攻击反击、伤害数字、生命状态和声音共享原有接触拍。

`fx-profiles.js` 中 62 个 ID 均显式注册，新增未注册卡牌会被测试和运行入口明确发现，避免静默套错表现。反制后的大法术仅在施法者处收束，不向目标发出不存在的陨火。减弱动态跳过新纹理解码和动态队列；取消、旋转、离开和关闭演武场清理效果，规则结果仍只提交一次。

## 素材和技术预算

选用作者公开发布的 [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) 和 [Mikodrak 2D Spell Effects](https://opengameart.org/content/2d-spell-effects)，均标注 CC0。新增 9 张透明纹理与 5 套动画图集。完整许可、原件、哈希、公共裁切区域与落点锚点见 [素材台账](../assets/vfx/README.md)。没有迁入暴雪游戏文件。

- PNG 合计 **1,275,635 字节**，基础解码 RGBA **11.25 MiB**；最大图集 1024 px，动画格 128 px，静态遮罩 256 px。
- 静态染色缓存最多 48 格；有色动画仅复用一块 128×128 的临时画布校正当前帧，不复制整张图集。包括最大缓存的 RGBA 上限约 **23.31 MiB**。
- 新队列桌面最多 96、触屏 48、低特效 24 项；连同旧粒子的总预算仍是 800 / 360 / 220。达到上限先牺牲碎片和星点，保留各目标的核心命中。
- 共用原有 `EmberFX.tick`，没有新增 RAF、游戏逻辑定时器或远程请求。局部透明纹理和组合几何替代大面积模糊、全屏闪白。光效按实时攻血徽章的位置留出圆形可读区域；位移反应也会随帧跟踪。
- `python3 build.py` 只用标准库。`.venv/bin/python tools/repack_vfx.py` 从保留原件重建后，14 张成品哈希全部一致。
- 本次构建网页 **10,848,840 字节 / 215 文件**；便携单文件 **14,211,622 字节**。音效和特效均随单文件内嵌，网页使用本地内容哈希文件。

## 实测

运行 `node tools/probe-vfx.cjs`，在真实七目标烈焰风暴期间逐帧采样；同时捕获三个布局的演武场和实际首领觉醒。结果在 `artifacts/qa/vfx-metrics.json`。

| 本机 Chrome 布局 | 样本帧 | 新 VFX CPU P95 | rAF 间隔 P95 | 新队列峰值 | 新 VFX 平均 CPU |
|---|---:|---:|---:|---:|---:|
| 桌面 1600×940 | 79 | 0.50 ms | 16.8 ms | 96 | 0.225 ms |
| 触控竖屏 390×844 | 80 | 0.30 ms | 16.8 ms | 48 | 0.163 ms |
| 触控横屏 844×390 | 80 | 0.30 ms | 16.7 ms | 48 | 0.141 ms |

这是 headless 本机 Chrome 的 Canvas 合成 CPU 采样与 rAF 间隔，手机仅为布局/触控模拟；不等同于实体手机帧率、整机 GPU 性能或端到端声音延迟。`maxDraws` 记录本模块的部分绘制原语计数，不是 WebGL draw call 数。上述场景解码约 11.75 MiB，三种布局均完成真实首领二阶段触发。

## 独立视觉复查

复查者查看了最初的完整 66 张截图（before 12、after 32、signatures 22）与三种视口测量，未读取实现源码。保守评价：美术方向 2/3、可见 VFX 由 1/3 提升到 2/3、性能证据 2/3；当时横屏演武场裁切使 UI/HUD 降为 1/3。严格 3D 类别和静态截图无法证明的时序不评分，不计算完整十类平均值。

据此修复：横屏演武场将舞台和操作区同时容纳在视口内；打开演武场清掉上一场景尾迹并立即建立裁剪区域；攻血徽章前的光雾被圆形避让，星界入口的中心烟雾减弱；新增七类普通攻击实战截图。龙翼是轻量几何与纹理组合，仍属于风格化符号，未宣称达到独立电影级角色动画。

初审者明确认为表现辨识度已有提升，同时不足以通过严格 premium/AAA/showcase 验收。本轮接受这一边界，以真实事件反馈、可读性和有预算的运行实现作为交付结论。

第二轮独立复查覆盖更新后的 signatures 全部 31 张，包括七类普通攻击：横屏操作区确认完整，UI/HUD 恢复为 2/3；普通攻击的来源、目标与数字可辨。弓箭/投矛的接近表现、龙息束与龙翼的简化造型仍是后续美术精修空间，不用静态截图替代动作时序结论；接触同步由实际浏览器行为测试覆盖。

最终同名截图覆盖后，独立复查者再次读取 `nyx-touch.png`、`frostking-touch.png`、`frostking-desktop.png`，确认攻血周围矩形空白边已消失，圆形徽章完整、数字清楚；其余评分和边界沿用第二轮结论。
