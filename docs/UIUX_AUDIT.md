# UI/UX 审计与改造 · v0.12.1

2026-09-08。基于真实浏览器页面与计算样式复核，而非只看源码。

## 问题与改造

| 页面 | 复现的问题 | 处理 |
|---|---|---|
| 遗物选择 | 旧浅绿色底继承新浅金文字，正文 12px；原始组合对比度约 1.34:1 | 安静纸面与深色规则字，正文 16px/1.65，对比度 11.24:1 |
| 遗物决策 | 整备表单抢占首屏；点任意遗物立即进入下一关 | 三件遗物为主；点击只选中，可切换，确认后推进；换牌为折叠次级步骤 |
| 遗物识别 | 心脏、透镜等旧图案近似，图标语义不明确 | 六张独立原创图：红宝石心、蓝透镜、王冠、银羽、火晶、红旗 |
| 主菜单 | 标题在面板外，重复英文、宣传句及多处分散装饰竞争注意力 | 标题与主要动作放入一个中心柜体，减少冗余文案，保留已有入口 |
| 面板与按钮 | 棕色平面、细边框，缺少受光与重量感 | 胡桃木材质、古金包边、上沿高光、内凹阴影、底部厚度；统一焦点与按下状态 |
| 收藏 | 底部应用按钮被挤出；长触发规则压到攻血 | 牌表滚动，操作区固定；收藏卡规则自然排版，数值保留独立底部空间 |
| 地图 | 浅色标题落在浅纸上；锁定状态降低整张卡透明度 | 深色文字，锁定只弱化原画；章节状态和说明可读 |
| 玩法手册 | 加粗文字深棕、关键词暗绿落在深棕背景上 | 独立纸面规则区，统一深色文字，加大字号，长内容滚动 |
| 设置/触屏菜单 | 字小、旧绿色控件混入、说明重复 | 统一材质与字号，开关有足够触控面积，删去重复说明 |
| 手机遗物 | 旧绝对定位图片扩张到卡片大小，覆盖规则 | 图片恢复局部布局，限制在奖牌容器，图片与文字不得相交 |

## 参考与取舍

查阅并实际查看了暴雪官方 [酒馆战棋第八赛季饰品界面](https://hearthstone.blizzard.com/en-us/news/24119592) 的截图：木质底板、厚边框、独立图标、浅色规则面和先选后确认。此次借鉴这些信息与材质层次，保留项目的原创卡图、人物、Canvas 酒馆和实时 DOM 数值。未复制炉石图标、卡框或商标。

面板质感通过现有木纹素材与 CSS 边框/阴影表达，不是真实三维模型。刻意让正文区域保持安静，不把材质噪点叠在规则字上。

## 验证范围

- 构建、82 项规则/应用/素材单元测试、4 项独立美术检查。
- 浏览器套件共 60 项。整套首轮 59 项通过，长卡底部空间检查发现问题后修复；随后复验全部 10 项 UI/UX 与相关收藏、材质及战役整备流程。覆盖 1600×940、1280×800、1024×768、768×1024、390×844、844×390、320×568。
- 遗物正文对比度至少 4.5:1；实际新纸面为 11.24:1。图标边界包含、不与正文重叠、按钮中心可命中。
- 选择与切换遗物不提前推进；确认携带正确遗物进入下一关；超出同名上限的整备被阻止。
- 键盘空格选择；正文从 16px 放大到 32px 后不溢出卡片，确认仍可到达。这是局部文字放大检查，不等同于整站 200% 浏览器缩放验收。
- 地图与手册文字对比度、桌面牌组应用按钮可达、桌面和手机长卡文案不覆盖攻血。
- 截图覆盖主页、英雄选择、设置、收藏、地图、手册、战斗、遗物；保留于本地 `artifacts/uiux/`。脚本 `tools/audit-ui.cjs` 可再生成。
- 原真实来源存档、战役奖励推进、触屏旋转、完整控件对局、只读接口和离线单文件回归继续执行。

未获得实体手机、Safari、色觉用户或真实玩家可用性访谈验收。小尺寸战斗手牌仍是紧凑摘要，完整规则依赖查看详情；本次扩大了收藏与奖励阅读区，不把所有战斗文字强行放大遮挡棋盘。
