# 英雄与卡组模型验收 · 2026-09-08

## 变更范围

英雄/职业分离，默认牌表引用预设，职业与种族注册，统一构筑规则和内容校验，多套命名卡组、旧数组延迟迁移，以及由首领目录长度驱动的战役流程。三个现有英雄的默认牌表逐项比对改动前版本，卡牌 ID 与顺序完全一致；没有新增正式英雄、卡牌或首领。

## 覆盖场景

- 同职业第二英雄在规则和浏览器中共享卡池/预设，独立技能和身份正确恢复；新职业、新种族能够通过内容配置注册。
- 重复 ID、未知字段、非法默认牌表、错误目标和失效引用在加载时失败；非法开局不改变现有状态。
- 调整构筑牌数和同名上限后，内容加载、开局与编辑使用相同规则。
- 旧卡组读取不写盘；明确保存后迁移；两套命名卡组跨刷新存在、可以分别选用。改名/另存不覆盖另一套卡组。
- 旧混合职业卡组保留供编辑，旧 v1 战役继续支持混合职业。损坏 JSON、未知版本与写入失败不会覆盖原值或报告成功。
- 浏览器仅注入第二英雄/第六首领配置后，完成选英雄、组牌、第五关奖励、第六关跨刷新恢复、最终通关及地图六关完成标记。
- 遗物已经集齐时仍可进入下一关。非法第三张同名牌的战役整备不推进关卡、不修改牌表；合法替换可继续。
- 已查看命名卡组桌面、390×844 和 844×390 触屏截图。完整回归还覆盖音画反馈、老存档恢复、离线单文件、只读 API、触屏旋转与一整局练习对战。

## 边界

浏览器验收为本机 Chromium 与触屏模拟，不代表实体手机或其他浏览器。线上站点未更新。战役仍使用 v1 的 bossIndex：追加首领受支持，重排/删除旧首领及修改已发布构筑规则仍须先设计存档迁移。光环、墓地及任意触发时点不在本次范围。
