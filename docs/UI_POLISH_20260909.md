# 星火酒馆界面精修 · 2026-09-09

基于 2026-09-08 的炉石视觉差距审计，在现有 v0.14 游戏中完成本轮界面精修。目标是统一器物材质、提高决策信息的可读性、消除主要面板与手机控制区的布局缺陷。没有更换规则引擎、卡牌内容或 79 张角色原画，没有发布到线上。

## 素材与实现

原创生成素材为 `assets/ui/starfire-seal.webp` 与 `assets/ui/cabinet-rim.webp`，合计约 140 KiB。源 PNG 有透明通道；边框中央保持透明，卡名、费用、规则与数值均为实时 DOM。制作简报与处理参数见 `assets/ui/PROMPTS.md`，校验信息见 `assets/ui/manifest.json`。

中文展示字体使用系统字体栈，未随包分发字体文件；不同操作系统的字形可能略有差别。样式集中在 `src/presentation/components.css`，延续 legacy → layout → theme → components 层级。`tools/ui_assets.py` 在构建时校验源和运行素材 SHA-256，生成忽略提交的 `src/ui-assets.js`。普通构建无需 Pillow 或在线生成服务。

## 验证

`npm run test:release` 全部通过：116 项规则/应用/素材单元检查、6 项美术检查、107 项浏览器回归（约 4.9 分钟）。最终截图复核后另微调桌面英雄技能文字等高与收藏页脚留白，并重新构建、复验相关 UI 套件，20 项全部通过。

新增浏览器回归检查四组尺寸的主菜单入口、英雄/设置固定确认区、技能/契约/回合控件互不遮挡、契约进度石与弹窗遮挡 toast，以及收藏折叠反复打开关闭的异步事件安全。新增单元检查验证源图、WebP 与最终嵌入内容完全一致。

本地截图由 `UI_LABEL=polished-20260909 node tools/audit-ui.cjs` 生成，覆盖桌面 1600×940、竖屏 390×844、横屏 844×390 的首页、收藏、英雄、设置、对局、奖励，以及桌面地图和手册。补充 568×320 入口与控制区检查。截图位于忽略提交的 `artifacts/uiux/`。

## 结论边界

本轮完成的是可运行、可复验的视觉与交互精修。不能以自动化通过数量宣称已经达到《炉石传说》的整体商业美术质量；动画导演、手绘资产密度、声音打磨和真实玩家体验仍需持续评审。现有音效与战斗动画保留并回归，没有把它们宣传为本轮新增。

浏览器触屏模拟不等同实体手机验收；本轮没有实体 iOS/Android、Safari 或真实玩家盲测。小屏战斗手牌仍采用摘要与详情配合，收藏和长面板允许自然滚动。线上站点未更新。
