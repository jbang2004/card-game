# 手牌完整展开与顶部状态区 · 2026-09-19

## 改动

- 点击任意手牌会展开可交互的完整卡面。手牌横向滚动容器原本会裁切上移内容，现在展开节点直接归属 app，原位留淡色占位，不改变其他牌的位置。
- 阅读状态与出牌状态独立。法力不足、场上已满、对方回合等情况仍可阅读；顶栏持续说明原因，不进入瞄准或消耗资源。可出的牌需战场/目标二次确认，也可从展开牌继续拖动。
- 展开卡面根据实际规则行数分配正文空间，取消正文截断；费用、卡名、攻血保留实时 DOM。入场 180ms，减少动态设置下不播放抬升动画。
- 再点展开牌、顶部取消、Esc、右键手牌均可收起；只读情况下点击外部只收起，不穿透执行其他动作。切换手牌、滑动原手牌栏、打开弹窗或切换尺寸都会正确处理阅读状态。
- 卡牌飞行及瞄准线从当前展开位置取得起点；新的技能操作先清理手牌阅读状态。
- 竖屏为导航下方预留 44px 状态行，导航自身仍为 52px；横屏和桌面使用顶栏中央，临时替换回合文字。通知暂时替换操作说明，通知结束后恢复；无操作时竖屏显示简短手势提示。
- 移除竖屏战场中央原先为通知预留的大间距，矮屏随从恢复更大的显示尺寸。

展开层在阅读期间会遮住部分战场，顶部取消始终可用。需要选择被展开卡遮挡的目标时，可从展开卡拖向目标；拖动开始即撤下阅读卡。没有添加整屏遮罩。
