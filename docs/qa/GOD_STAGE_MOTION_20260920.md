# 神契布局、滑动与死亡消散 · 2026-09-20

## 修改

- 手机神契入口按当前英雄尺寸放在英雄正上方，间隔 12px。竖屏战场预留左侧神契通道；横屏英雄栏利用屏幕底部高度，与右侧手牌分开。极短横屏仍使用既有小头像布局，神契与该头像同等大小。
- 神卡一次指针序列只翻一页，边界不重复刷新说明；捕获滑动后的兼容点击，避免松手又选到别的卡。触屏不再计算鼠标视差倾斜。
- 关闭时读取所有卡当前姿态，取消入场错峰，再统一翻背收回同一神契位置。入场未完成也支持关闭。以未变换的容器计算共同落点，避免桌面焦点上移导致落点偏差；清除废弃 flying 数据标记。
- 修正横屏多卡误用单卡布局的分支，卡片侧翼与仪式说明之间保留真实伸出宽度，解决中间卡聚焦时侧卡压字。
- 死亡闪现根因：公共动画完成回调取消 WAAPI，死亡节点在后续定时清理前短暂恢复原样。死亡卡与消散光边现在以透明作为底层最终状态，取消动画不会重新显现；规则结算与死亡时序不变。
