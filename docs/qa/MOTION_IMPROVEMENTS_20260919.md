# 动效语义与跨尺寸改进 · 2026-09-19

本轮从实际运行链路修复动效问题，并用手机竖屏、横屏、矮横屏和桌面满场画面检查信息层级与操作遮挡。规则、卡牌数值、胜负逻辑没有改变；没有发布到公开站点。

## 已完成的改进

| 问题 | 实施结果 |
|---|---|
| 引擎可用，但首次加载的几何特效 canvas 隐藏 | 异步创建后同步最新舞台尺寸与可见状态；首次加载测试不再切换画质绕过问题 |
| 冰系普通攻击、月矛看起来像冻结 | 编译每个目标的实际 outcome；冰膜只随真实冻结，月矛使用银紫色伤害表现 |
| 灵魂系结误用吸血回流 | 独立支持效果 soulbind：从施法者到友方的结纹，不做敌方吸血或受伤后坐 |
| 圣盾、全护甲仍出现受伤语言 | 消除对应肉身命中声、穿刺/切口、受伤后坐；受阻箭矢短暂偏转，保留护甲/破盾反馈 |
| 群攻第二个目标起全部静音 | 施法声一次，各目标按实际接触时刻播放命中；音量按目标数衰减，并使用各目标档位 |
| 两个控制器相互保存临时姿态 | 统一 motion-feedback 合成、限幅与复原；家族适配器不再直接管理 DOM |
| 龙息长尾掩盖下一次操作 | 原采样器和 shader 保留，命中后宿主时间压缩三倍；尾部上限 4.1s → 1.4s；新序列让旧余韵在 140ms 内退场 |
| 减少动态仍有整卡冲撞、后坐与补位位移 | 这些位移停止，保留数字、状态文字与规则结果；移除没有对应规则的“重击”字样 |
| 手机七卡满场时生命角标被遮挡 | 堆叠卡的生命角标内收到可见条带；逐个数值中心进行遮挡命中测试 |
| 窄卡上的致死飘字过大 | 按目标卡宽度缩放；最低 38px，普通最高 64px、强命中最高 76px |
| 矮横屏的起手提示换行挤占顶部 | 缩短文字，保留行动指引 |
| 大屏技能按钮透明边角截获随从点击 | 技能与契约槽下移，按钮整个点击范围离开七卡随从行 |

## 自动验证

- 构建通过；679 项 Node 规则、素材与表现测试全部通过。
- 15 项动效、满场、旋转、减动态与 DOM 回退专项浏览器测试通过。
- 三种尺寸 × 9 类技能共 27 次检查，首次 canvas 均可见，回看不改变规则状态，未记录页面异常。
- 完整 287 项 Playwright 回归全部通过，0 失败、0 重试后通过、0 跳过，用时 13.7 分钟。桌面与手机因果矩阵、真实结束回合、拖放/滑动、布局切换、窗口旋转、技能签名及响应式组件均包含在内。
- `git diff --check` 通过。原始火焰、Renderer、engine、cards、campaign、timing 的历史哈希保持一致。

完整日志归档为图集目录中的 `release.log`、最终源码的 `unit-tests.log` 与 `playwright-results.json`。最后补充了全部剑技的格挡裂纹断言，因此最终单元测试数为 679。

新增验证不仅检查对象存在，还检查实际规则事件与表现的对应、不同家族重叠后恢复原始 inline style、群攻每个目标的命中、减动态时正在运行的位移动画数量，以及满场攻血值中心是否被其他控件拦截。

既有整卡代理测试明确运行于 WebGL 不可用的回退环境。几何路径使用真实卡牌和共享姿态，不再错误要求它生成旧 `.attack-actor`。原始火焰、Renderer、规则与 timing 文件仍通过历史哈希检查；改动的语义模块通过行为断言验证。

## 验收边界

这些结果来自本机 Chrome 和 Playwright 的触屏/视口模拟。没有实体手机的温升、耗电与持续帧率测试，也未覆盖 Safari/iOS WebGL 差异，因此不作真实手机性能验收结论。极窄满场仍使用卡牌重叠与长按详情；本轮解决信息遮挡，没有把手机改成桌面等比缩放。
