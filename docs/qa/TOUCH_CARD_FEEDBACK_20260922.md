# 触摸倾斜与战斗提示 · 2026-09-22

## 改动

- 修复普通放大卡与神契卡直接忽略 touch 指针的问题；浮雕光照跟随同一触摸输入。
- 阅读卡面注册触摸所有权，避免触摸页上其他控件时误转卡片；横向抚摸、松手、pointercancel 均有处理。列表卡保留纵向原生滚动，手牌保留原有拖放和横滑。
- 起手换牌 / 发现选项的抚摸不再兼容触发 click；点按、鼠标、键盘原操作保留。
- 召唤疲劳使用三个上升排列、厚描边、高对比的 Z，与关键词共存。仍放在原状态子树中，战斗代理同步时一起更新。冻结优先；减少动态时取消浮动。
- 放置 / 瞄准箭头增加深色厚边、连续高光与立体分面箭头。红色渐宽箭身、橙红亮面和暗红厚边，合法性与落点计算不变。

## 分段箭身与遮挡修复

- 箭身使用有透明间隙的渐宽短段，移除连续中轴，缩小箭头与厚边。箭头层 66、抬起手牌/拖动卡 65、弹窗 70；指示层不截获点击。
- 新回归断言检查箭头高于预览手牌、分段数量和 pointer-events；已检查 390 与 1600 战场截图，手机预览上方可以完整看见箭头。
- 构建与 682 项单元测试通过。三个专项 24 项通过，568×320 用例在游戏初始化等待处超时；单独重跑通过（共 25 个不同用例最终通过）。未做实体手机验收。

## 粗箭身与浮空拱线

根据用户最新批注加粗分段与箭头；左右法线偏移改成屏幕 Y 轴高度投影，中段按高度加宽，分段侧厚及地面投影辅助表达悬空。保持端点、层级与点击穿透。构建、682 项单元测试、action-feedback 与 touch-card-feedback 共 24 项通过；补充无横向偏移/中段抬升几何断言后，桌面与手机两个用例再次通过。已查看 battle-390 与 battle-1600 实装截图。仅 Chromium 模拟验证。

## 空间带状投影实现

- 两侧边缘、侧厚、箭头使用同一倾斜透视相机，不再按屏幕曲线法线加宽。弧长采样固定 49 点，手机最多 14 段、桌面 20 段，共用路径，箭身不使用模糊滤镜。
- 构建与 682 项单元测试通过；原两个交互专项 24 项通过。新增横屏及投影端点、有限坐标、段数上限断言，三个视口专项通过；调整拱高后再次 3 / 3 通过。总计 25 个不同交互用例。
- 已检查 1600、390、844 实装图。没有实体手机帧率测试，也没有前后 GPU 耗时对比；分段上限和滤镜减少属于开销控制，不能等同于实测性能结论。
