# 移动手牌与英雄外框修复 · 2026-09-19

手机手牌不再按剩余宽度压成重叠扇形，改为完整卡宽、8px 间隔，超过容器宽度时原生横滑。桌面排列不变。悬停、焦点、选中状态也允许横滑，避免旧 `touch-action: none` 规则阻断横屏滑动。

所有触屏尺寸统一移除英雄外层面板的背景、边框、阴影与轮廓线；极窄竖屏和矮横屏的圆形头像也不再带矩形底板。选中、可攻击、合法目标的反馈在头像上显示，键盘焦点轮廓同样落在头像上。头像自身轮廓与血量等信息保留。
