# 回合与通知合并翻转栏 · 2026-09-19

本轮替代同日上一轮的竖屏双行布局。`#battle-status` 是唯一几何容器，回合、操作说明和短通知属于它的三个显示面。

- 优先级：短通知 → 当前操作说明 → 回合。更新合并到同一帧，连续切换操作不会闪出回合。
- 有消息时回合向上位移并绕 X 轴翻出；所有消息结束后向下翻回，时长 240ms。消息从下方翻入，父容器裁切。减少动态设置和系统偏好下直接切换。
- 高对比深蓝壳、浅蓝描边、亮蓝操作说明、暖红错误通知，保持实时文字。
- 手机竖屏单行顶栏高 64px，声音/设置仍可通过菜单进入；取消按钮保持至少 44px，桌面缩放另补偿命中尺寸。酒馆沿用自己的 52px 顶栏，避免影响主页按钮布局。
- 回合显示面仅在动画结束后隐藏，通知结束后恢复；读屏属性与显示状态同步。

构建与 679 项 Node 测试通过。44 项相关 Playwright 用例完成通过：原合并运行 43 项通过、360×640 酒馆按钮受顶栏高度影响一项失败；限制新增高度只应用于战斗页后，该项重新通过。涵盖通知翻转及恢复、减少动态、提示/取消、手牌展开与拖放、英雄装备、断点切换。没有重新执行全量浏览器测试。
