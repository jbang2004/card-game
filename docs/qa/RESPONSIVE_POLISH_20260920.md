# 通知材质、英雄神契与手牌浏览 · 2026-09-20

本轮继续 9 月 19 日的布局改进，覆盖之前高饱和通知样式。

后续神契尺寸、滑动与死亡闪现修复见 [神契交互回归](GOD_STAGE_MOTION_20260920.md)。下文保留本轮初始验证记录。

## 实施

- 通知容器改用现有 `--slate-pill` 半透明材质与轻度背景模糊，取消蓝/红实色背景，以字重、文字阴影和错误文字的暖色强调消息。保留回合翻转与减少动态设置。
- 桌面宽度 420px；手机/平板取可用顶栏空间与 420px 的较小值，居中放置，不再把通知拉满宽屏。
- 移动端神契改为英雄操作区的独立 44×44 入口，保留契约数量、可唤醒/已使用状态和打开完整神卡舞台的能力；手牌栏不再预留神卡宽度。桌面神卡位置保留。
- 左右渐隐箭头仅提示相应方向的隐藏手牌，到边界即隐藏，全部牌能放下时两侧均不显示。提示节点不接收触摸，避免遮挡边缘卡牌拖拽；继续使用原生横向滑动。
- 手势只更新缓存的滚动位置和两侧提示状态，不读取布局。渲染/尺寸变化后的测量、位置恢复共享一个 requestAnimationFrame；没有轮询或额外滚动实现。
- 清除上一轮单独消息定位的 CSS、闲置的回合/操作栏布局副本、废弃 CSS 变量写入和空的通知定位函数。

## 验证

构建通过；679 项 Node 测试通过。94 个不同的相关 Playwright 用例最终通过，分组执行，包括既有提示/回合、契约、英雄装备、手牌、断点切换回归，以及新增 6 个材质/神契/滑动提示检查。没有执行全量浏览器回归。

验证中发现可点击箭头会抢占边缘卡牌的拖拽起点，因此移除该点击机制，改为不接收事件的提示层，再跑全部手牌拖拽回归。滚动聚焦测试改用 10 张牌明确制造溢出，避免手牌变宽后原测试牌数已经能放下。吸附撤销测试从固定时延改为等待真实状态，横竖屏均通过；行为断言未放宽。

新增检查覆盖：提示透明材质、宽屏宽度上限、神契不占手牌/不压武器与技能/可打开神卡舞台、左端/中间/右端提示、提示不拦截触摸、浏览不改变对局状态，以及牌数减少后隐藏提示。
