# 武器与战场布局统一检查 · 2026-09-19

## 修复结果

1. **武器漂到中央**：桌面仍继承早期英雄居中时的全局武器坐标；移动端另用头像左侧的近似位置，反而遮住头像。武器现在是英雄组件的子节点，桌面相对英雄定位，移动端用英雄内部坐标。旋转、缩放、装备更新、耐久消耗与武器损毁都走同一归属。
2. **窄屏信息互相遮挡**：320px 竖屏原来的 124px 回合按钮盖住血量、护甲和名字。所有移动尺寸统一 64px 回合按钮，为武器、技能、生命/护甲、法力分别保留位置。手机攻击值直接在武器上显示，去掉旁边重复的攻击芯片。
3. **横屏状态挤入另一位英雄**：敌方攻击、护甲、契约进度与手牌数改为头像右侧的多行排列；左侧栏按实际内容扩大，玩家状态另占一行。短横屏使用一致的紧凑芯片规格。
4. **满法力数字换行**：`10 / 10` 保持单行，竖屏晶体间距随剩余空间压缩，横屏数字拥有独立宽度。
5. **名牌重复偏移**：名牌本来就在头像内部，旧 CSS 却再次加上整个英雄栏的偏移。现在名牌直接贴头像下沿，超长名称省略，完整名称仍在英雄说明中。
6. **聚焦手牌导致整个战场滚动**：底部手牌只露出部分高度，浏览器的聚焦/scrollIntoView 可能把 overflow:hidden 的战场当作滚动容器，导致视觉位置与战场坐标不一致。战场与 app 改用 overflow:clip，手牌保留独立横滑；新增强制聚焦与滚动断言。
7. **横屏提示与回合文字叠印**：提示或瞄准说明占用顶栏时暂时隐藏回合文字，提示结束后自动恢复。
8. **冻结覆盖整个英雄栏**：冰冻材质与雪花限制在头像内，不再覆盖血量、装备和技能区域。

没有修改规则引擎、卡牌内容或存档格式；没有发布线上。
