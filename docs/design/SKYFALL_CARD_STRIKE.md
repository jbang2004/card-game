# R5 · 屏幕外垂直贯入目标卡牌

## 用户验收目标
从屏幕上方之外突然垂直插入目标卡面。命中后由插入点产生裂纹。
不是回引挥砍，不是倾斜坠落，不是落在卡牌脚下。R4 原版火焰保持原样。

## 实际实现
- 新增 `src/vfx3/skyfall.js`，使用既有 `Ember3D.Renderer`，不新增 WebGL 上下文。
- 剑的最下方尖端初始位于舞台上边界外至少 40 个舞台像素；剑身向上延伸，所以初始完整模型都在屏幕外。
- 只用接触前最后 120ms（随现有 timeScale 缩放）。位置使用 `0.28u + 0.72u²` 单调加速；不使用命中前的 ease-out。
- 屏幕 x 恒定，z 恒定。屏幕旋转恒为 180°；固定的 -0.22rad 面朝向仅用于显示金属厚度，不产生侧摆或回引。
- 插入点为卡心下方 `0.10 × 卡高`，位于原画内；接触时间沿用原导演层的绝对时间，不延后伤害。
- 插中后不再抽回或回弹，剑在原位停留并淡出。装饰阶段不新增伤害或输入锁。
- 独立空气轨迹不是拉长的剑模型；低对比速度线在命中后 35ms 内消失。
- 金属分面、剑槽、护手、缠柄、镶晶都是几何构件；所有部件共享同一个刚体变换。
- 卡面裂纹有九条不规则主裂纹和五条分支，分支出生进度继承主裂纹节点。暗缝、窄断边、内侧细光和穿孔前沿分开绘制。
- 裂纹限制在目标卡原画区内，避开相邻卡牌和底部数值区域。裂纹在 160ms 内展开，在命中后 960ms 内消失。
- 固定大小碎片按出生时间计算弹道，星芒、碎片和淡尘分别消散。
- 启用三维天剑时，攻击者只有短后坐，不再沿用整张卡片冲到目标的近战克隆体；关闭三维/减少动态时仍走现有回退。

## 代码边界
`skyfall.js` 不读写规则、DOM 或存档，不建立计时器。`runtime.js` 只委托当前 slash 的绘制与测试姿态；喷火和闪电绘制函数不变。
`src/vfx3/reference-flame.js` 和 `src/vfx3/renderer.js` 与 R4 的 Git blob 哈希完全一致，由新增单元测试锁定。
对 R3 的“回引/撤剑”测试改为新的垂直/定刃要求；保留刚体长度、接触和规则隔离测试。

## 验证与边界
执行 `python3 build.py`、`python3 tools/vfx3/export_demo.py`、`node --test tests/*.test.cjs`。
定向运行 `xvfb-run -a python3 tools/vfx3/verify_skyfall.py`：真实规则攻击、无双实例、血量、离屏进入、垂直不漂移、刚体、逐帧、WebGL 回放像素一致、清理、手机横竖屏与减少动态。
本次本地 HTTP 导航被执行环境策略阻止，因此检查采用完整导出演示的内存加载，不称作真实 HTTP/file 来源验收。
背景与 DOM UI 有独立时间，像素回放检查只比较同步采样的实际三维画布 PNG，不把全页面的环境动效变化误判为特效不确定性。
真实目标仍为 DOM 原画；裂纹与穿孔为临时三维覆盖效果，不改变卡牌图片或规则。跨 DOM 的完整三维遮挡及实体设备/浏览器性能不在本轮验收范围。
