# R4: flame-only direct source port

Scope: preserve the 2D dragon card, do not import the dragon geometry.

`src/vfx3/reference-flame.js` contains the original `dragon()` and `spark()`
methods verbatim, original quintic envelope and PRNG precision. The mouth
function retains the original reference motion as an emitter frame only.
`renderer.js` uses the original mode-8 flame GLSL verbatim; the smoke GLSL is
also unchanged. No new procedural fire reinterpretation is used.

Host adaptations: the existing authoritative contact time is not changed.
The short pre-contact portion maps reference 0.72–1.46 seconds to the game's
existing wind-up; after that reference time advances at 1:1 (subject to the
existing sequence timeScale). The original flame/smoke lifetime is preserved;
visual cleanup is 4.1 seconds after contact at scale=1. This tail does not
add damage or block rules. Practice-floor scorch and ground glow are omitted
because they do not represent a state effect in the card game. Other particles
are unchanged. Reference-view positions undergo uniform scale + rigid rotation;
individual flames are never stretched along the attack axis. Background and
viewpoint compositing differ, so this is source fidelity, not pixel equality.

Lightning and the existing R3 sword recipe are unchanged. Full dragon model,
source demo rig, UI, sound and floor are not part of the port.

## Compositing boundary
Original flame/smoke shading and CPU outputs are retained. The existing
transparent DOM-overlay path remains, so its final pass applies the original
0.97 exposure and tone curve to premultiplied energy before computing a
coverage-safe straight-alpha output. This avoids low-alpha pale fog without
rewriting flame noise. Practice-stage scorch/floor illumination are excluded,
and contact glows are gated by the authoritative game contact time.

## Validation scope
32 original output frames (16 times × 2 density settings) were generated by
executing the actual reference Effects, timeline and mouth transform in Node VM.
SHA-256 fixture hashes compare all returned fields after 1e-6 quantization.
The unchanged-method and unchanged-GLSL hashes above document source fidelity;
they do not claim identical final pixels over two different backgrounds.
The R3 flame-specific tests were replaced because their custom trajectory no
longer exists; sword, lightning and lifecycle tests remain.
