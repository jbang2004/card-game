# 琥珀卡框

2026-09-28 · 设计稿，实验室原型已完成，未接入游戏。

用户反馈（同日）：第一版把手牌做成挂在皮带上的琥珀块，"感觉很奇怪"；要求**基本上还是卡牌，只是外框像琥珀**。本稿按此重做，第一版只留在 git 历史里（commit 16f8f62）。

设定依据：[SETTING_AMBER.md](SETTING_AMBER.md) 第三节、第十一节。每张牌是一块琥珀；法力是持有者的火种之温；出牌是把琥珀焐热、唤醒里面的生命。

原型：`tools/amber-lab/`（8012 端口起本地服务后打开 `/tools/amber-lab/`）。截图：[战场](img/amber-frame-battle.jpg)、[图谱上半](img/amber-frame-tray.jpg)、[图谱下半](img/amber-frame-tray-2.jpg)。

## 一、不变的与改变的

**不变**：卡牌的形状和比例（5 : 7.4）、版式和位置。插画在上方，名字在 57–65% 高度，规则在下方，费用在左上，攻击在左下，生命在右下。手牌扇形、悬停拿起、拖动出牌都不变。文字仍是实时 DOM（`AGENTS.md` 的约束）。

**改变**：

| 部位 | 现在 | 琥珀卡框 |
|---|---|---|
| 外框 | 一条细描边 | 一圈抛光琥珀珠边：半透明，会把压在下面的插画边缘折射出来，里面有气泡和太阳花，随视角出现高光 |
| 插画与规则之间 | 渐隐 | 一道琥珀横梁，名牌钉在上面 |
| 规则底板 | 深蓝面板 | 深色干邑琥珀，带细微的流纹 |
| 名牌 | 深色胶囊，描边是阵营色 | 金属名牌，**金属就是稀有度**：古铜（普通）、银（稀有）、紫银（史诗）、金（传说） |
| 稀有度 | 底部金属条 | 名牌金属；外框顶端镶一颗宝石（蓝、紫、红）；包角（银、紫银、金）；史诗的外框是切面；传说有世界树叶冠和光晕 |
| 底部 | 稀有度金属条，写"随从 · 法师" | 加厚的琥珀底边，"随从 · 法师"刻在上面 |
| 费用 | 烟色玻璃圆章 | 黄铜温度章：法力够时烧红，不够时是冷铁色 |
| 攻击 / 生命 | 菱形 / 心形 | 黄铜六角 / 一滴血珀；武器耐久用盾形 |
| 可出的牌 | 绿色描边光 | 琥珀框**从里面亮起来**，外面一圈暖光 |

**琥珀的颜色就是职业**：蜜珀（中立）、金珀（圣卫）、绿珀（游侠）、蓝珀（法师，表面泛蓝荧光）。这四种都是天然琥珀的真实品种。

## 二、交互

| 时刻 | 表现 |
|---|---|
| 悬停 / 长按 | 卡牌升起放大；琥珀框跟着指针折光，太阳花闪烁，插画轻微呼吸 |
| 新回合 | 一团暖光从左往右扫过手牌，经过哪张能出的牌，哪张的框就亮起来 |
| 抽牌 | 卡背飞入手牌，翻面 |
| 出牌 | 卡牌飞到场中，琥珀越烧越亮，裂纹透出光，碎成琥珀片和树脂滴，里面的生命走出来；接现有的召唤与 3D 登场 |
| 法力不够 | 卡牌抖一下 |
| 卡背 | 一块封着火种（太阳花）的琥珀；黑玉之界的敌人用黑玉卡背 |

## 三、渲染

- 一个 WebGL2 上下文画所有卡框（`EmberAmber.paint(canvas, spec, state)`）。画布比卡牌四周各大 7%，用来放叶冠和光晕。静止的卡牌按"冷 / 热"两种状态各画一次，切换时淡入淡出；拿在手里的那一张每帧重画。
- 着色器的做法：卡牌减去"插画窗"和"规则窗"，剩下的就是框。框上每一点落在由最近两条边围成的一条带里，按带宽做成圆珠截面（史诗做成平台加倒角的切面）。沿法线把压在框下的插画或底板折射出来，再按琥珀品种做吸收，加上自发光、气泡和太阳花、柔光箱反射和高光。包角、宝石、叶冠也都是程序化生成的。
- 不需要新图片：用现有卡图（336×448）、浮雕高度图和摄影棚环境图。渲染器约 20 KB 脚本，Artifact 体积几乎不变。

## 四、接入计划

1. `tools/amber-lab/amber.js` 移到 `src/presentation/amber.js`，登记进 `config/build.json`；纹理来源换成 `EmberArt.card(c)`，浮雕图用和 `card-relief` 相同的资源解析。
2. `EmberCards.cardHTML` 的结构不动（`.card-title`、`.card-copy`、`.card-cost`、`.stat` 这些选择器保留，e2e 与无障碍标签都不用改）。在 `.card-inner` 里加一张琥珀画布，取代现在的描边、渐隐和底部金属条；名牌、费用章、攻血宝石只改皮肤样式，写在 `skins/slate/card-face.css`。
3. 范围先定手牌、拿起的卡、起手换牌、发现和奖励三选一。收藏页一屏几十张，先用 CSS 近似版（琥珀色渐变框），不跑着色器。
4. 拿起：`card-relief` 手牌场景改为活画琥珀框；插画本身的浮雕视差保留。
5. 出牌：放到战场上时先播约 0.6 秒的"焐热—裂开"，再接现有的召唤动画。
6. 对手手牌 `#enemy-hand .card-back` 与牌库换成琥珀卡背；按对手阵营选琥珀或黑玉。
7. 降级：没有 WebGL2 时用 CSS 近似版；开了"减少动效"时不做活画、不播碎裂。
8. 测试：新增烘焙缓存与冷热切换的单元测试；截图类 e2e 的基线图需要更新。
