# 琥珀卡牌

2026-09-29 · 设计稿，实验室原型已完成，未接入游戏。

方向的演变，都是用户在同一段对话里逐步给出的：

1. 第一版（16f8f62）：手牌是挂在皮带上的琥珀块，卡上的内容也改了（纸签、只露名字）。用户觉得"很奇怪"。
2. 第二版（09877a6）：卡牌形状不变，只有外框是琥珀。用户提议改成：**外形是琥珀，卡片的内容不变**。
3. 本稿：卡牌整体是一块琥珀，轮廓是蛋形的琥珀弧面，内容与现在的卡牌完全一致。

设定依据：[SETTING_AMBER.md](SETTING_AMBER.md) 第三节、第十一节。每张牌是一块琥珀；法力是持有者的火种之温；出牌是把琥珀焐热、唤醒里面的生命。

原型：`tools/amber-lab/`（8012 端口起本地服务后打开 `/tools/amber-lab/`）。截图：[战场](img/amber-shape-battle.jpg)、[图谱上半](img/amber-shape-tray.jpg)、[图谱下半](img/amber-shape-tray-2.jpg)。

## 一、不变的与改变的

**不变**：卡上的全部内容和它们的位置。插画在上方约 60%，名字在中间，规则在下方，费用在左上，攻击在左下，生命在右下，类型标签在最底部。卡牌的宽高比（5 : 7.4）也不变，所以手牌扇形、悬停拿起、拖动出牌、无障碍标签都不用改。文字仍是实时 DOM（`AGENTS.md` 的约束）。

**改变**：

| 部位 | 现在 | 琥珀卡牌 |
|---|---|---|
| 轮廓 | 圆角矩形 | 蛋形的琥珀弧面，上窄下宽；插画窗因此成了拱形 |
| 外缘 | 一条细描边 | 一圈抛光琥珀珠边：半透明，会把压在下面的插画边缘折射出来，里面有气泡和太阳花，随视角出现高光 |
| 插画与规则之间 | 渐隐 | 一道琥珀横梁，名牌钉在上面 |
| 规则底板 | 深蓝面板 | 深色干邑琥珀，带细微的流纹 |
| 名牌 | 深色胶囊 | 金属名牌，**金属就是稀有度**：古铜（普通）、银（稀有）、紫银（史诗）、金（传说） |
| 底部 | 稀有度金属条，写"随从 · 法师" | 加厚的琥珀底边，"随从 · 法师"刻在上面 |
| 费用 | 烟色玻璃圆章 | 黄铜温度章：法力够时烧红，不够时是冷铁色 |
| 攻击 / 生命 | 菱形 / 心形 | 黄铜六角 / 一滴血珀；武器耐久用盾形 |
| 可出的牌 | 绿色描边光 | 琥珀**从里面亮起来**，外面一圈暖光 |

**琥珀的颜色是职业**：蜜珀（中立）、金珀（圣卫）、绿珀（游侠）、蓝珀（法师，表面泛蓝荧光）。这四种都是天然琥珀的真实品种。

**切工与镶嵌是稀有度**：

| 稀有度 | 切工 | 镶嵌 |
|---|---|---|
| 普通 | 滚磨的原形，轮廓略不规则，哑光 | 无 |
| 稀有 | 抛光弧面 | 银丝包边，顶端一颗蓝宝石 |
| 史诗 | 切角：轮廓的肩部切成平面，切面处折射出彩光 | 紫银包边，顶端一颗紫晶 |
| 传说 | 抛光弧面 | 金边，顶端一颗红宝石，世界树叶冠，光晕 |

**外形随类型微调**（内容布局三者完全相同）：随从是泪滴形（上窄下宽），法术更圆，武器是切角形。

## 二、交互

| 时刻 | 表现 |
|---|---|
| 悬停 / 长按 | 卡牌升起放大；琥珀跟着指针折光，太阳花闪烁，插画轻微呼吸 |
| 新回合 | 一团暖光从左往右扫过手牌，经过哪张能出的牌，哪张就亮起来 |
| 抽牌 | 卡背飞入手牌，翻面 |
| 出牌 | 卡牌飞到场中，琥珀越烧越亮，裂纹透出光，碎成琥珀片和树脂滴，里面的生命走出来；接现有的召唤与 3D 登场 |
| 法力不够 | 卡牌抖一下 |
| 卡背 | 一块封着火种（太阳花）的琥珀，同样是蛋形；黑玉之界的敌人用黑玉卡背 |

## 三、渲染

- 一个 WebGL2 上下文画所有卡牌（`EmberAmber.paint(canvas, spec, state)`）。画布比卡牌四周各大 7%，用来放叶冠和光晕。静止的卡牌按"冷 / 热"两种状态各画一次，切换时淡入淡出；拿在手里的那一张每帧重画。
- 轮廓是一个带锥度的超椭圆（n 约 2.5–3.3），由程序算出到边缘的距离；普通卡给轮廓加噪声，史诗卡再切掉肩部。
- 卡牌减去"插画窗"和"规则窗"，剩下的就是琥珀。它上面的每一点落在由最近两条边围成的带里，按带宽做成圆珠截面（史诗做成平台加倒角）。沿法线把压在下面的插画或底板折射出来，再按琥珀品种做吸收，加上自发光、气泡和太阳花、柔光箱反射和高光。包边、宝石、叶冠也都是程序生成的。
- 不需要新图片：用现有卡图（336×448）、浮雕高度图和摄影棚环境图。渲染器约 22 KB 脚本，Artifact 体积几乎不变。

## 四、接入计划

1. `tools/amber-lab/amber.js` 移到 `src/presentation/amber.js`，登记进 `config/build.json`；纹理来源换成 `EmberArt.card(c)`，浮雕图用和 `card-relief` 相同的资源解析。
2. `EmberCards.cardHTML` 的结构不动（`.card-title`、`.card-copy`、`.card-cost`、`.stat` 这些选择器保留，e2e 与无障碍标签都不用改）。在 `.card-inner` 里加一张琥珀画布，取代描边、渐隐和底部金属条。名牌、费用章、攻血宝石只改皮肤样式，写在 `skins/slate/card-face.css`。
3. 因为轮廓不再是矩形，需要三处配套改动：插画窗用同一条轮廓做遮罩（或直接在画布里画插画）；规则文字的左右留白从 9% 加大到 17%，并按字数分三档字号（原型里 6.2 / 5.6 / 5cqw）；攻血宝石和费用章各往肩部挪几个百分点，压在琥珀的边缘上。
4. 拿起：`card-relief` 手牌场景改为活画琥珀；插画本身的浮雕视差保留。
5. 出牌：放到战场上时先播约 0.6 秒的"焐热—裂开"，再接现有的召唤动画。
6. 对手手牌 `#enemy-hand .card-back` 与牌库换成琥珀卡背；按对手阵营选琥珀或黑玉。
7. 降级：没有 WebGL2 时用 CSS 近似版（蛋形 `clip-path` ＋ 琥珀色渐变）；开了"减少动效"时不做活画、不播碎裂。
8. 范围：先做手牌、拿起的卡、起手换牌、发现和奖励三选一。收藏页一屏几十张，先用 CSS 近似版，不跑着色器。
9. 测试：新增烘焙缓存与冷热切换的单元测试；依赖矩形卡面的截图类 e2e 基线要更新；命中区域要用蛋形轮廓，避免透明角落误触。
