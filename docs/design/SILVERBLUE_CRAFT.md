# 银蓝风格 · 移动端细节精修

2026-09-12。本轮针对移动端排版、文字对比、滚动呈现、卡牌徽章与组件轮廓继续打磨。保留现有 Canvas 与 DOM 分工，未改变规则、卡牌内容和存档格式。

## 设计与交互

- 收藏页在手机上默认收起筛选，保留结果摘要；展开后可搜索类型与费用，切换卡组后保持筛选状态。短横屏整合工具栏，首屏能看到完整卡牌及详情操作。
- 英雄页缩小不必要的纵向留白，平板名册与设置使用适配布局；契约与手册重新整理窄屏信息密度。
- 提高次级文字与禁用文字的对比，明亮插画上的说明增加文字阴影。禁用状态由底色、边框表达，避免整体透明导致不可读。
- 触屏隐藏横向、纵向滚动条，移除明显的底部滚动提示条；保留内容滚动和手势。
- 恢复已有 SVG 费用宝石、攻击刀刃、生命心形及耐久盾牌。数字仍为实时 DOM，加入清晰描边与阴影；短横屏随从加宽并压缩高度，避免攻血徽章重叠。
- 主按钮使用不对称圆角和内沿高光，次按钮与筛选标签使用更柔和的轮廓；弹窗、输入框与信息卡保持统一形态语言。
- 修复关闭卡牌放大视图后，下一次独立点击偶尔被短时拦截的问题。保留原有长按与拖动保护。

## 结构

颜色、徽章与组件轮廓集中在 `src/presentation/components.css`，响应式排版在现有 `polish-mobile.css`，弹窗和触屏滚动呈现在 `polish-dialogs.css`。未增加新的 CSS 层或运行依赖。

收藏筛选状态归属 `src/application/library.js`。短横屏单位尺寸由 `src/mobile-view.js` 的共享坐标函数决定，渲染与命中区域使用同一尺寸；不以视觉缩放制造坐标偏差。
