## 元素拆分与当前实现

- 实现入口：`src/application/screens/preferences.js`；统一材质由 `src/presentation/components.css` 消费，场景由 `EmberTheme` 的语义角色解析。
- 范围：音量滑杆、声音开关、画面开关、操作导航、完成与即时持久化。
- 位图只承担场景、复杂材质、遗物和徽记；文字、数值、规则、选择状态与按钮保留实时 DOM；简单图案由 `EmberArt` 原生 SVG 提供。
- 新生成素材的提示词、源文件、格式、SHA-256 和 Alpha 实测见 [provenance.json](../../../assets/ui/page-reference-v1/provenance.json)。生成模型未由工具返回，记录为未核实；WebP 仅作格式封装。生成重建不等于无损分层。

## 批注与迭代结论

排除了旧 absolute/margin/广泛选择器造成的覆盖；桌面卡牌维持同一图区比例和按规则长度变化的字号。横屏提示移出单位区域，敌方法力移到英雄旁。新增设置导航、模式按钮和契约槽位均绑定实际状态。

已知差异：参考包含与当前内容库不同的卡名、数值、配置与装饰性文案，实装显示当前真实内容；背景和复杂徽记为图像重建，纹理与边界不是原图逐像素复制；部分细边框、字形、按钮轮廓仍由现有主题及 SVG 重建。没有计算排除卡图后像素误差为零，不能将交互测试通过称为像素一致证明。

## 2026-09-14 触控布局皮肤

`?skin=slate` 第二阶段：行的发丝线、开关药丸与其蓝色开启态、滑杆、节标题字体等材质改由 `html[data-skin="slate"] body` 提供；桌面 `[260px][1fr]` 轨 + 内容几何留在 `body:not(.touch-layout)`。

触控几何：竖向导航轨（2px 竖线 + 56px 发光节点）是桌面装置，触控下同一个 `nav` 改成设计系统的另一个既有组件「文字分页」——整宽横排、选中项 3px 白色下划亮条。按钮本身的字体、颜色与 hover / active / focus 反馈一条不改，只隐藏竖线和节点圆。该横排不画竖线分隔：`::before` 是节点圆、`::after` 是下划亮条，两个伪元素都已占用，硬塞分隔线会让选中项旁边那一条消失。

`.audio-level` 竖屏改为「标签 + 数值一行、滑杆整宽一行」，短横屏（≤500px 高）压回单行 `[标签][滑杆][数值]`，行高约 50px，390px 高的窗口无需内层滚动即可逐行滑出——这修掉了基线里「音量行在 390px 高窗口放不下」的问题。开关按简报改为 88×36（滑块 28px）。

`components.css` 只在 `body:not(.touch-layout)` 下给 `.settings-section-heading > span` 定字号，触控下会掉回 12px/700 的旧手机值；皮肤里重述了桌面同样的字重（400）并给出触控字号。

验收：三个分页 × 四个视口的截图见 [output/slate-mobile-pages-20260914](../../../output/slate-mobile-pages-20260914/)。
