# 图鉴与构筑 / library

## 目标与当前状态

牌组编辑器现共用 [SVG 四角面板](../SHARED_PANELS.md)。展开工具时沿用外层纵向滚动，移除短横屏的嵌套滚动与固定最小高度；图鉴全屏外壳不加装饰框。

2026-09-13，按 concepts 中对应参考接入既有可玩游戏。当前已实装，未发布；用户尚未确认视觉验收。卡牌插画继续使用当前严格 ID 映射；卡名、规则、数量和状态取真实游戏数据。

## 元素拆分与当前实现

- 实现入口：`src/application/library.js`；统一材质由 `src/presentation/components.css` 消费，场景由 `EmberTheme` 的语义角色解析。
- 范围：搜索、类型与费用筛选、五列卡牌、卡组条目、费用曲线、保存与详情。
- 位图只承担场景、复杂材质、遗物和徽记；文字、数值、规则、选择状态与按钮保留实时 DOM；简单图案由 `EmberArt` 原生 SVG 提供。
- 新生成素材的提示词、源文件、格式、SHA-256 和 Alpha 实测见 [provenance.json](../../../assets/ui/page-reference-v1/provenance.json)。生成模型未由工具返回，记录为未核实；WebP 仅作格式封装。生成重建不等于无损分层。

## 页面动作

入口：主页「万象秘典」。所有按钮沿用既有动作接口；测试中的状态夹具用于打开胜负、发现和奖励页面，不进入生产接口。

## 批注与迭代结论

排除了旧 absolute/margin/广泛选择器造成的覆盖；桌面卡牌维持同一图区比例和按规则长度变化的字号。横屏提示移出单位区域，敌方法力移到英雄旁。新增设置导航、模式按钮和契约槽位均绑定实际状态。

已知差异：参考包含与当前内容库不同的卡名、数值、配置与装饰性文案，实装显示当前真实内容；背景和复杂徽记为图像重建，纹理与边界不是原图逐像素复制；部分细边框、字形、按钮轮廓仍由现有主题及 SVG 重建。没有计算排除卡图后像素误差为零，不能将交互测试通过称为像素一致证明。

## 2026-09-13 细节打磨

顶部导航、卡牌类型和费用各使用一个独立移动高光条，支持悬停、焦点与选中归位。调整搜索/筛选锚点；牌组操作使用冰晶与深蓝纹理按钮，费用曲线恢复银蓝渐变。

复杂纹理由 image-gen 重建，简单图标与轮廓由原生 SVG/CSS 完成。生成图并非原图无损分层；具体透明通道限制见 素材记录（该素材记录已随 2026-09-14 旧主题移除删除）。本次截图和检查见 [细节打磨记录](../../../output/detail-polish-20260913/VALIDATION.md)。

## 2026-09-13 组件纪律修正

费用数字统一为 15px，操作按钮的文字独立居中；窄侧栏纵向排列，短横屏横向排列。「另存副本」保留原有创建新牌组行为。费用曲线常规窗口固定在列表外，短横屏随列表滚动，窗口切换时移动同一节点。卡牌采用独立的晶体／剑／心形 SVG，删除已不再执行的旧徽章定义。检查新增 `component-discipline.spec.cjs`，截图见 `output/component-discipline-20260913/`。

## 2026-09-14 触控布局皮肤

`?skin=slate` 第二阶段：材质（卡片网格、`详情` 小药丸、筛选芯片、牌组行的圆角描边与右侧半透明卡图、牌组预览节标题）统一到 `html[data-skin="slate"] body`，桌面的 `[1fr][380px]` 双栏几何留在 `body:not(.touch-layout)`。

触控几何跟随 `dialog-layout.css` 既有的 `@container dialog (max-width: 799px)` 断点，不另立断点：窄对话框用单列 + 「全部卡牌 / 我的牌组」文字分页（白色下划亮条、44px 命中区），宽对话框（844×390、1024×768）保留卡牌 + 牌组双栏并重新隐藏该分页。竖屏为 2 列卡牌网格；网格左右各留 16px 檐口，否则卡面外挂的攻血徽章会被裁掉。

`polish-mobile.css` 的银蓝手机方案把搜索框折进筛选面板、把分页与筛选摘要绝对定位到标题行上；皮肤层把三者放回文档流：搜索药丸单独占标题下一行（横屏与标题同排），筛选摘要恢复为可折叠行。皮肤层排在 `components` 之后，因此 `dialog-layout.css` 里「同一时刻只显示一个面板」的 `display: none` 需要在皮肤里重述一次。

验收：截图见 [output/slate-mobile-pages-20260914](../../../output/slate-mobile-pages-20260914/)。桌面 1672×941 计算样式与改动前完全一致（仅两个桌面下 `display: none` 的节点——触控分页与筛选摘要——获得了新的材质声明）。
