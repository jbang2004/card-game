# 遗物奖励 / rewards

## 目标与当前状态

奖励外壳与遗物选择区现共用 [SVG 四角面板](../SHARED_PANELS.md)；遗物选中态保留独立高亮，内边距与其他面板一致。

2026-09-13，按 concepts 中对应参考接入既有可玩游戏。当前已实装，未发布；用户尚未确认视觉验收。卡牌插画继续使用当前严格 ID 映射；卡名、规则、数量和状态取真实游戏数据。

## 元素拆分与当前实现

- 实现入口：`src/application/screens/campaign.js`；统一材质由 `src/presentation/components.css` 消费，场景由 `EmberTheme` 的语义角色解析。
- 范围：三件透明遗物、主动选择、牌组整备、确认进入下一关。
- 位图只承担场景、复杂材质、遗物和徽记；文字、数值、规则、选择状态与按钮保留实时 DOM；简单图案由 `EmberArt` 原生 SVG 提供。
- 新生成素材的提示词、源文件、格式、SHA-256 和 Alpha 实测见 [provenance.json](../../../assets/ui/page-reference-v1/provenance.json)。生成模型未由工具返回，记录为未核实；WebP 仅作格式封装。生成重建不等于无损分层。

## 页面动作

入口：战役胜利后「选择遗物」。所有按钮沿用既有动作接口；测试中的状态夹具用于打开胜负、发现和奖励页面，不进入生产接口。

## 批注与迭代结论

排除了旧 absolute/margin/广泛选择器造成的覆盖；桌面卡牌维持同一图区比例和按规则长度变化的字号。横屏提示移出单位区域，敌方法力移到英雄旁。新增设置导航、模式按钮和契约槽位均绑定实际状态。

已知差异：参考包含与当前内容库不同的卡名、数值、配置与装饰性文案，实装显示当前真实内容；背景和复杂徽记为图像重建，纹理与边界不是原图逐像素复制；部分细边框、字形、按钮轮廓仍由现有主题及 SVG 重建。没有计算排除卡图后像素误差为零，不能将交互测试通过称为像素一致证明。

## 2026-09-13 磨砂青岩皮肤

`?skin=slate` 下这一页从浮层壳提升为页面壳（在 `dialogs.css` 内覆盖 `[data-dialog-size="choice"]`，不改 base.css）：满屏磨砂材质、无边框圆角，标题行 + 发丝线 → 三张遗物卡（圆角 14、1.5px `--slate-card-line` 描边、`--slate-card-base` 底、遗物图 170px、名称 22px/700、说明 15px、「选择此遗物」小药丸；选中 = 蓝边 + 内描边 + 外发光 + 蓝色药丸）→「酒馆整备」由方框 `<details>` 改为发丝线分节（20px/700 节标题 + ink-3 补充 + 旋转 chevron，两个药丸下拉）→ 底部发丝线，左下「下一站 / 已选择」状态，右下主药丸「继续冒险」。决策区在标题与底栏之间垂直居中。

已知差异：1280×720 在战场视图下进入 `body.touch-layout`，皮肤不生效；桌面窄尺寸以 1360×768 验收。截图见 `output/slate-dialogs-20260913/`。

## 2026-09-14 触控布局皮肤

`?skin=slate` + `body.touch-layout` 下这一页同样用**页面壳**：满屏磨砂材质、无边框圆角投影，
内边距走安全区（竖屏 16/16/14，横屏 12/16/10）。这一点偏离了本轮触控简报写的「浮层壳 + 12px 边距」，
理由有二：`.rewards-box` 的边框 / 圆角 / 投影属于共享材质，`responsive-component-style.spec.cjs`
会拿它和桌面比对（实测浮层壳会产生 5 项差异）；而且满屏是三张遗物卡加「酒馆整备」在手机上唯一放得下的排布。

竖屏：遗物卡纵向堆叠，每张是 `76px 图 | 文字` 两列的圆角 14 描边卡，名称 17px/700、说明 13px、
「选择此遗物」小药丸靠左；选中仍是蓝边 + 内描边 + 外发光 + 蓝色药丸。横屏：三张并排、图在上文字在下；
高 ≤ 430px 时图 52px、说明 11px、药丸 30px，高 ≤ 350px 时图 40px、说明 10px、药丸 28px。
「酒馆整备」保持发丝线分节，字段在竖屏单列、横屏两列；页脚左侧「下一站 / 已选择」，右侧主药丸铺满余宽。

截图：`output/slate-mobile-battle-20260914/<尺寸>/rewards.png` 与 `rewards-selected.png`。
已知差异：568×320 下药丸仍需向下滚动才能看到（选中态由蓝边与外发光表达，整张卡都是命中区）。
