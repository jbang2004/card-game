# 手机横屏战斗 / battle-landscape

## 当前实现 · 2026-09-20 法师与神契上下重排

紧凑桌面和短横屏分别确定人物尺寸：法师上移进入场内、朝右露出侧脸，神契下移；矮横屏按可用高度控制尺寸，不把宽屏人物等比缩进原头像。

素材使用已有 Tripo 法师，不重做原画或动作。几何归属为 `src/presentation/skins/slate/hero-model.css` 与现有响应式布局模块，朝向归属 `src/presentation/hero-model.js`。本轮参考与最终验收见 `output/hero-stage-20260920/`；下方较早记录不作为本轮验收结果。

## 当前实现 · 2026-09-13

双方英雄沿左侧上下排列，中央保留两排随从；英雄卡面与手牌保持同宽同高比例，并复用卡牌的法力、攻击、生命、护甲徽章。技能和契约并排置于右上，回合操作与法力置于右下。提示区从英雄卡右侧开始，避免覆盖左侧英雄；矮横屏将双方英雄并排放在左上，再保留中央随从空间。回合信息统一置顶居中，最短屏压缩辅助文字。手牌保持本轮开始时的大小、比例与底部滑动排版，不重构卡牌。

指令与错误消息使用战场上方预留区域，不覆盖角色或手牌；取消按钮至少 44px，完整操作提示可见。控件与桌面共享银蓝材质和状态，不再加载旧的纹理按钮。缩放和旋转裁切同一张 Boss 场景，不更换场景身份、不重启对局。

几何由 `src/mobile-view.js` 与 `src/presentation/battle.css` 统一负责；材质位于 `src/presentation/components.css`。清理范围、桌面关联与历史来源见 [桌面档案](battle-desktop.md)。

## 2026-09-14 触控布局皮肤

`?skin=slate` 下横屏沿用同一套触控皮肤（`body.touch-layout` + `.mobile-landscape`），几何仍由
`src/mobile-view.js` 决定：双方英雄在左（矮横屏并排），中央随从，右上技能 + 契约，右下回合操作与法力。
皮肤把顶栏字标、36px 图标药丸、居中回合药丸、英雄 10px 描边卡与名牌药丸、技能发光节点、结束回合主药丸、
法力数字、深色药丸提示条与 44px 取消药丸全部换成 slate 语言，与竖屏、桌面共用同一份材质声明。

横屏专有调整：`#touch-match-chip` 按 `battle.css` 保持隐藏（皮肤重新声明 `display: none`）；
「诸神契约」是 48×44 的图标芯片，标签压到 10px、字距 0 并 `text-overflow: ellipsis`，不出药丸边；
「结束回合」占满 104px 指令轨（紧凑桌面 128px），高 52px（高 < 350px 时 44px）；
高 < 380px 的矮横屏两张英雄卡并排，`手牌 N` 芯片会压住敌方攻血徽章，按「空间不足先减装饰」隐藏该芯片。

对局弹窗（换牌 / 结算 / 奖励 / 发现 / 战术底板）在横屏走窄化的浮层壳：外边距 12px、壳内边距 12/16、
标题 19px、页脚药丸等宽铺满；菜单底板改 3 列，遗物奖励用页面壳并在 ≤430px / ≤350px 高度两级压缩装饰。
截图与已知差异见 `output/slate-mobile-battle-20260914/`（`844x390`、`568x320`、`1024x768`、`1280x720`）。

已知差异：技能节点 44px 而非 56px、「结束回合」104×52 而非简报的 140×52——两者的盒子由
`mobile-view.js` 内联写死，改尺寸等于改行为层，超出皮肤范围；命中区仍 ≥44px。
