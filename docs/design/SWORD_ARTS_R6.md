# SWORD ARTS R6 — 角色化剑光与剑气

## 范围与基线

本地实现基于 `feat/skyfall-card-strike` 的 `bb3de7859073a8a9037f57dd20a739dc2d8a1844` 源码快照。该分支基于已合并 R4 的 `main`（`9e5b06203fa020b479a7f174a811801c316e7dd5`）。本轮未推送 GitHub、未创建远程分支或 PR、未合并和部署。

保持原版火焰、卡池、规则、存档格式、二维卡面及页面布局。下表中的新名字仅是演出名称，不是新增规则技能，也不增加伤害次数。

## 视觉与几何

实体金属天剑不再在当前剑技绘制路径上创建或绘制。使用 `sword-arts.js` 的解析轨迹生成三维带状网格，分层表示有羽化边缘的外光、带细纹的剑气主体和窄亮锋线。不是把完整斩击视频贴在卡面上。

各角色改变形状、路径、宽度、速度曲线、命中后粒子方向与收束长度，不能仅靠颜色区分。普通兵使用短斩和短刺；垂直天剑保留给圣光、逐日与冰霜角色。三道剑气或交叉双刃共用一次权威接触，不产生多个规则命中。

所有带状轮廓从同一条解析路径采样，首端在 q=0 经过命中点；尾部沿路径前进并淡出，不用整体伸缩冒充运动。天降剑气在舞台上边界以外起步，进入和接触之间保持固定的横向位置。裂纹仅在接触后出现，限制在目标卡面内部；连续裂纹用完整分支网格绘制，不由多个明亮短棒拼接。

## 时间与接入

`fx-profiles.js` → `effects.js` / `combat.js` → `fx-stage.js` → `runtime.js` 将 `swordStyle`、来源身份和 targetRef 传到底层。规则目标、攻击族、原权威命中时刻不改变。剑气的可见起手压入已有 lead 时间，特效最长尾部不超过 runtime 的 1120ms（受 timeScale 缩放），不额外阻塞规则队列。

实际攻击后按 targetRef 读取目标受击位移，扣除特效画布的公共镜头变换后应用。回放固定在捕获位置，不重复伤害或重放整段 DOM 动作。目标删除时不将附着残留继续留在空槽。绘制依旧由宿主时钟驱动，不另开渲染循环。

## 原火焰保持策略

`reference-flame.js` 整个文件的 Git blob SHA 保持 `8aa26d97bbe4244a48c2a178926ba65baff96310`。

`renderer.js` 增加独立 mode 12 的剑气材质；不能声称整个渲染器文件哈希不变。移除显式标记的这一段后，其余文件逐字节等于原渲染器（blob SHA `0695ba6b0a07e1f43a157a9960d7b93a678f0824`）。既有火焰和烟雾着色分支、透明合成与后处理未改动。原火焰 32 组采样输出对照与 GLSL 一致性测试继续通过。

旧 `skyfall.js` 暂留作纯几何兼容检查；运行时不再调用 `Sky.create`。旧 `_swordPose` 只是历史诊断接口，当前画面应检查 `_swordArtFrame`，不能拿旧实体剑的几何测试替代剑气视觉验收。

## 文件职责

- `src/vfx3/sword-arts.js`：13 个可声明配方（12 个本轮演示映射及1个 shatter）、纯函数采样、同一 Renderer 的绘制适配。
- `src/vfx3/renderer.js`：只增加新 mode12 材质。
- `src/vfx3/runtime.js`：按身份选择剑气、附着目标、回放与结束清理。
- `src/presentation/fx-profiles.js`：角色／武器明确映射。
- `tools/vfx3/lab.js`：只在检查导出版本显示角色选择、真实动作按钮和时间轴；不是可视化创作编辑器。

## 验证

最终 Node 测试 316 项：308 通过、8 项因未入库源素材跳过、0 失败；包含新增 52 项映射、轨迹、材料隔离、定种采样与时序检查。

定向 Chromium 167 项全部通过，包括十二次角色／武器实际攻击的正确样式、单实例、单次伤害、多个时间点 GL 检查、回拖不改变规则、结束清理；同时回归原喷火与闪电，检查低画质和减少动态。390×844 与 844×390 是独立布局测试，不是连续方向切换验收。没有执行全量 E2E。

检查环境是 Xvfb / Chromium / ANGLE OpenGL / Mesa 软件渲染，采用内存加载构建代码；没有验收真实 HTTP 或 file 来源存档、Safari、实体手机和硬件性能。测试通过不等于用户已认可美术品质。
