## 〇、30 秒版本

> 深炉城靠挖矿发了财：矿里出产的以太晶，是魔法与蒸汽机共同的燃料。飞艇、列车、魔导卡，全城的繁华都靠它。两年前，矿工挖穿了一座远古迷宫，怪物从矿井里爬了出来。王国封了矿，冒险者公会贴出悬赏。于是城里最热闹的铜壶酒馆，每天都有人背着卡匣下井。
>
> 没人知道的是，以太晶根本不是矿石。它是八百年前众神封印巨龙阿什拉时砌下的墙。整座城，一直在拆自己的牢笼。

一句话：**一座靠拆封印致富的蒸汽魔法城市，和从它脚下醒来的龙。**

## 一、三个参照，各取什么

| 参照 | 取什么 | 落在哪里 |
|---|---|---|
| 《龙与地下城》 | 冒险者小队、酒馆接任务、层层深入的地下城、战利品、各司其职的神、各色种族、龙 | 基本玩法和世界结构：酒馆 → 地下城八层 → 龙 |
| 魔法蒸汽时代 | 魔法与机械并存、学院与工坊、飞艇列车、进步与代价、新技术与旧信仰的冲突 | 时代背景、能源设定、主要矛盾 |
| 《罗德岛战记》 | 各有来历的英雄群像、精灵与矮人的恩怨、光与暗的大战、远古封印与复苏、灰色地带的人物 | 主角们的关系、历史、结局的格局 |

**写法原则**：每个设定都要能用一句大白话讲清楚。不需要哲学，不需要玩家读完所有文字才明白。

## 二、世界一览

**深炉城**：王国东部的矿业之城，建在一座死火山的山腹上。高炉、烟囱、蒸汽升降机、晶石路灯，街上跑着蒸汽马车，天上停着飞艇。上城是学院区和贵族区，下城是矿工街和工坊区。

**铜壶酒馆**：冒险者公会的据点，开在旧一号矿井的井口上方，大堂中央就是封起来的井口（向《龙与地下城》里建在地下城入口上的酒馆致敬）。接悬赏、组队、买卖战利品、喝酒，都在这里。

**深矿与迷宫**：井下前两层是废弃矿道，再往下是远古迷宫，最底下是龙。迷宫是众神为关住巨龙而建，墙会移动，所以每次下去地形都不一样。

**周边**：
- **银叶林**：城西的精灵森林。
- **铁砧山**：城北的矮人氏族，蒸汽机的发明者。
- **王都**：远在西边，只关心晶石税。

## 三、历史：三个时代

1. **神话时代**：火龙**阿什拉**焚烧大地。四位神与第一代国王**奥德里克**联手，把它困在火山深处，用神力砌成层层迷宫与晶墙封印。国王留在封印前，把自己冻成最后一道锁。
2. **王国时代（约八百年）**：封印的故事渐渐成了童话。人们在山上建城，发现岩层里的发光晶石可以储存魔力，称之为**以太晶**。学院靠它研究魔法。
3. **蒸汽魔导时代（近五十年）**：矮人的蒸汽机加上学院的以太晶，引发了一场魔导革命：飞艇、列车，以及每个冒险者都在用的**魔导卡**。深炉城从小镇变成大城。矿越挖越深，晶石越挖越多，直到两年前挖穿了迷宫。

|---|---|---|---|
| **冒险者公会**（铜壶酒馆） | 各路冒险者 | 只看悬赏 | 中立卡，远征的起点与补给 |
| **星穹学院** | 人类法师，魔导卡的发明者 | 支持开矿，相信进步 | 法师 |
| **黎明骑士团** | 太阳神索兰的骑士，驻守矿口 | 守护城市，却早已忘记自己最初守的是什么 | 圣卫 |
| **银叶林** | 精灵猎人与野兽 | 反对开矿：地下的封印松动后，森林开始枯死 | 游侠（薇丝珀） |
| **月神殿** | 月神瑟弥拉的渡魂人 | 为死去的矿工送行 | 游侠（莫菈） |

| **灰烬教团** | 崇拜阿什拉的秘密教派 | 想唤醒巨龙，得到它的力量 | 首领、敌方卡组 |

**种族**：人类、精灵、矮人为主，另有兽人、半巨人等。现有插画里的赤岩狂战士可以定为有巨人血统的兽人。

## 五、众神与仪式

四位神各管一样东西，各自回应一种信徒。现有的唤醒规则全部保留，解释改成一句大白话：

| 神 | 形象（沿用现有插画） | 司掌 | 唤醒条件 | 为什么 |
|---|---|---|---|---|
| **阿斯泰尔**（原星焰神·烬辰） | 雌雄莫辨、头戴星盘的星火神 | 星辰、奥术 | 施放 6 种**不同**的法术 | 奥术之神只欣赏博学者，重复念同一个咒不算本事 |
| **索兰**（原曙日神·奥瑞恩） | 手持日盾的巨人骑士 | 太阳、誓约 | 圣盾被**敌人**击破 4 次 | 誓言要在挨打时守住才算数 |
| **芬洛斯** | 生着金角的白色狼狮 | 荒野、狩猎 | 野兽猎杀敌方**随从** 6 次 | 他只认真正的狩猎：猎物是野兽和怪物，不是人 |
| **瑟弥拉** | 月之女神 | 月亮、亡者 | 8 次阵亡、4 个**不同**的灵魂 | 她为每个灵魂领路，每个灵魂只领一次 |

另外：
- **神只来一次，也不直接攻击英雄**。神降临战场是恩典，不是替你杀人。
- **为什么神在变弱**：蒸汽时代的人不怎么祈祷了，神力也在衰退。封印松动，一半是因为挖矿，一半是因为没人信了。这是"新技术与旧信仰"的矛盾。

## 六、四位主角

四个人来自四个势力，出身和立场各不相同，像《罗德岛战记》那样组成群像。每次远征选一人做领队。

| 主角 | 身份 | 为什么下去 | 与谁对照 |
|---|---|---|---|
| **艾莉娅**（人类法师） | 星穹学院最年轻的魔导卡刻印师 | 她的导师、学院首席**维克托**三个月前带队下矿，没有回来 | 深渊先知（其实就是维克托） |
| **雷昂**（人类圣骑士） | 黎明骑士团驻矿口的小队长 | 矿难那天，他的小队被困在下面，只有他被推上了升降机 | 冰封古王（骑士团的创始人） |
| **薇丝珀**（精灵游侠） | 银叶林的猎人 | 森林在枯死，野兽在发狂。她不信任人类，但需要公会的通行证 | 荆棘女王（发疯的森林之灵） |
| **莫菈**（月神殿渡魂人） | 替死者领路的修女 | 死在矿里的矿工不肯安息，一群群爬回地面 | 月之守门兽（封印前的守护者） |

## 七、首领与地下城八层

| 层 | 地方 | 首领 | 他是谁 |
|---|---|---|---|
| 1–2 | 废弃矿道 | **敌对冒险者小队**（现"劲敌"） | 同样来抢悬赏的冒险者，用四位主角同职业的预设卡组 |
| 3–4 | 灰烬之门 | **灰烬狂战士·格鲁什**（原灰烬监守） | 灰烬教团的打手，守着通往迷宫的门 |
| 3–5 | 地下密林 | **荆棘女王** | 森林之灵。封印的魔力外泄，让她在地下疯长，也让她痛得发狂。不是坏人 |
| 5–7 | 无光圣所 | **深渊先知·维克托**（原深渊先知） | 学院首席、灰烬教团的真正首领。他想取出龙心，做成永不枯竭的能源 |
| 5–7 | 永冻王座 | **冰封古王·奥德里克**（原霜狱君王） | 八百年前自冻为锁的第一代国王。他以为你是来放龙的 |
| 6–7 | 月蚀祭坛 | **月之守门兽**（原断契监誓者） | 瑟弥拉留在封印前的守护兽，考验来者是否配走到最后 |
| 8 | 龙之巢 | **焚世之龙·阿什拉**（原终焉巨龙） | 被封了八百年的火龙 |

**规则层面的解释**：
- 每层二选一 = 迷宫的岔路。
- 中途的酒馆 = 公会用蒸汽升降机在第 2、4、6 层设的前哨站。
- 失败重来 = 公会的月神殿能复活倒下的冒险者，但你带下去的卡和财宝都留在了井下。

## 八、主线：三幕与三个结局

**第一幕：井下（第 1–2 层）**。和别的冒险者抢悬赏，在矿道里看到灰烬教团的记号。

**第二幕：迷宫（第 3–5 层）**。发现迷宫是众神造的牢笼，也发现以太晶就是牢笼的墙：挖得越多，龙醒得越快。之后撞见教团首领，他是学院的首席。

**第三幕：封印（第 6–8 层）**。遇见冰封的古王和月之守护兽，得知八百年前的约定，最后面对醒来的阿什拉。

**三个结局**：
1. **斩龙**：杀死阿什拉。封印不再需要，以太晶随之黯淡，蒸汽魔导时代走到尽头，深炉城要学会不靠晶石过日子。
2. **重封**：和古王一起重新封印。城市保住了繁荣，但立下《深炉协定》，永不再挖过某一层。
3. **真结局：新约**（四位主角各通关一次后开启）。学院的技术、骑士团的誓约、精灵的森林、月神殿的祷告联手，造出一座新的封印炉。它既关住龙，也让城市安全地取暖。这是新旧和解，也是人类、精灵、矮人的大联合，是《罗德岛战记》式的收束。

## 九、卡牌在世界里是什么

| 规则 | 一句话解释 |
|---|---|
| 卡牌 | **魔导卡**：学院和矮人发明的刻印晶片。法术卡存着一道术式，随从卡是一份召唤契约 |
| 牌组 | 插在腰间卡匣里的一叠卡，冒险者的标准装备，就像火枪 |
| 法力（每回合 +1，上限 10） | 卡匣里的以太晶芯每回合升温一次，最多撑到十格 |
| 以太硬币 | 一小片备用晶石 |
| 随从 | 在公会登记过契约的佣兵、战士和驯服的野兽，被卡片召唤到身边 |
| 召唤后要等一回合 | 契约传送需要时间 |
| 衍生物不留灵魂、不计入仪式 | 衍生物是法术变出来的幻影和傀儡，不是真正的生命 |
| 传说卡只能带一张 | 每位传奇人物只和公会签了一份契约 |
| 契约栏里的神与契兽 | 神殿开出的祷告卡：不是契约，而是请求 |
| 遗物 | 迷宫里捡到的古代宝物 |
| 金币、买牌、删牌 | 在公会前哨站交易魔导卡 |

关键词（嘲讽、圣盾、潜行……）都保持原样，不需要额外解释。

## 十、命名方案

**游戏名**：
- **《蒸汽与龙》**（推荐）：一眼看懂题材和卖点，搜索未见同名游戏。
- 《深炉城》：地点式命名，搜索未见同名。
- 备注：《龙脉》系列、《卡尔德拉》都已有作品在用；"龙晶"是《龙与地下城》艾伯伦设定的术语，也有同名游戏，都要避开。

**改名对照**：

| 现在 | 改为 | 理由 |
|---|---|---|
| 烬域 / 鎏金酒馆 | 深炉城 / 铜壶酒馆 | 具体、有工业感；"鎏金"被判定俗气 |
| 星焰神·烬辰 | 阿斯泰尔 | 与其他神统一为西式名 |
| 曙日神·奥瑞恩 | 索兰 | "奥瑞恩"是星座名，放在太阳神身上会混淆 |
| 荒猎神·芬洛斯、冥月神·瑟弥拉 | 保留名字，称号改为"狩猎之神""月之女神" | 名字本身没问题 |
| 灰烬监守 | 灰烬狂战士·格鲁什 | 有名有姓、身份清楚 |
| 深渊先知 | 深渊先知·维克托 | 与艾莉娅的主线挂钩 |
| 霜狱君王 | 冰封古王·奥德里克 | 讲清他是谁 |
| 断契监誓者 | 月之守门兽 | 原名太拗口 |
| 终焉巨龙 | 焚世之龙·阿什拉 | 与传说卡"终焰·阿什拉"统一 |
| 余火、初火一类字眼 | 以太晶、封印 | 用具体的物件代替抽象的比喻 |

四位英雄与大部分卡牌名都保留。

## 十一、对现有内容的影响

- **不用重画**：全部 97 张卡、神、首领和六个首领战场。
- **要新画**：首页（蒸汽城市远景）；铜壶酒馆可沿用现有酒馆画面，加一块招牌。
- **文案**：游戏名、神与首领的名字、首页与远征页的文字、首领台词、主角开场与结局、卡牌短文。
- **可选的新系统**：结局抉择（最后一战前选择斩龙或重封）；按主角解锁的剧情章节。
- **以后的扩展方向**：矮人与蒸汽机械系列（新种族"机械"）、灰烬教团系列、火枪手类新英雄。这些都自然长在这套世界里。
