# R7 三种标杆剑技：分镜到实时演出

## 范围与状态

基于已合并 main `9e5b062`，并纳入之前仅本地交付的 R6 差异剑技。
这一轮精修 `paladin / assassin / frostking`，其余 R6 角色身份保留。
正常游戏界面、二维卡面、卡池、伤害、存档与战役均不改变。

三张生成分镜是视觉目标，不是游戏实测截图。此实现用现有 WebGL 渲染器
和实时几何完成对应的凝聚、释放、接触、卡面残迹、消散，不承诺逐像素复刻。
刺客没有脱离卡牌成为全身三维角色；冰霜薄膜不是新增的冻结状态。

## 三招的区别

| 角色 | 主要形态 | 接触后的变化 | 余韵上限 |
|---|---|---|---|
| 圣光裁决者 | 屏幕上边界外垂直贯入的金色刃面，薄亮边与内部流纹；星形圣印、双层细环 | 有限的下压反应、接触闪芒、卡面分叉断纹；剑光从刃面拆解成上升光点 | 接触后 1440ms |
| 夜幕刺客 | 95ms 内抵达的窄紫黑锋线，深色实体与亮缘同轨，三条细影尾 | 沿入射方向的短促反应、单一暗切痕、少量紫白碎点 | 接触后 720ms |
| 白霜之王 | 最多 140ms 的晶体竖刃，硬折面、晶冠和冷光细边 | 临时颗粒状冰膜、枝状冰裂、立体碎晶与淡雾，晶体崩散而非圣光消散 | 接触后 1710ms |

各招的接触时刻沿用原导演层 `contactAt`，而非在画面中重新判定伤害。
凝聚段适配该次攻击已有的起手时间；尾迹不阻塞规则队列。
所有卡面痕迹在插画范围内生成，不改卡牌文本或数值，不永久修改原图。

## 模块边界

- `src/vfx3/benchmark-arts.js`：三个纯时间采样配方、有限刚体反应、专属几何、
  卡面裂纹、临时冰膜、碎晶与粒子；渲染仍使用同一个 `Ember3D.Renderer`。
- `src/vfx3/renderer.js`：只在 R6 的材质之后增加模式13/14/15/16：
  圣光、晶体、暗锋、霜膜。原火焰(8)、烟雾(9)、后处理路径保持不变。
- `src/vfx3/sword-arts.js`：原三种身份分派到新模块，其余 R6 招式继续使用原配方。
- `src/presentation/benchmark-feedback.js`：在同一帧把姿态应用到原 DOM 卡牌；
  只管理 inline transform/filter，保留 layout translate。结束或取消恢复原样。
  多实例叠加的目标位移限制为11px，避免连击把卡牌推离布局。
- `src/vfx3/benchmark-cues.js`：四个命名音效事件与确定性 PCM 合成，供游戏和录像共用。
- `src/platform/audio.js`：继续使用既有混音、静音、节点限额、音量与清理；
  对 benchmark 采样支持权威 `atMs` 的 AudioContext 调度，避免依赖 GPU 下一帧。
- `src/vfx3/runtime.js` 与 `src/presentation/fx-stage.js`：传递 sourceRef，
  统一 onEmit/onFrame/onClear，命中后几何跟随卡牌实时位置。
- `src/effects.js`：仅这三招由新反馈轨道管理来源动作、目标反应及专属声音，
  关闭重复的通用挥动/命中声与冲击；数字与规则因果仍交给旧导演。

## 时间定位与音频

正常对局：创建实例时按 start/impact 预定 charge/launch/impact/tail 音效。
静音、取消及页面隐藏由既有音频生命周期处理。三维运行时无独立 rAF。
演示回看：同一个采样器同时更新特效、来源卡和目标卡姿态；
不重放规则操作，不重复扣血，不重新制造伤害数字。
原速回看可以播放专属声音；慢放回看静音。暂停或切换速度停止现有音轨。
视频可以用 `benchmark-cues.timeline()` 导出同一组干声采样，避免独立配乐冒充游戏音效。

## 视觉限制

固定舞台与 DOM 卡牌仍不是完整三维世界；跨 DOM 遮挡与真实材质破坏有限。
透明冰膜是短时演出，不是完整物理冰层。金色剑气与阴影没有流体模拟。
相对分镜，正常尺寸表现有简化，不能把测试通过当作已达到商业游戏品质。
截图和视频必须使用实际程序输出，概念图不得作为实现截图。

## 验证

运行构建、全部 Node 测试与 `tools/vfx3/verify_benchmarks.py`。
精确测试覆盖：屏外起点、接触坐标、稳定刃面尺寸、无提前伤痕、时间缩放、
反向目标、有限刚体移动、定种输出、清理、脚本注册、PCM 峰值及音效调度。
浏览器覆盖真实动作与伤害、身份映射、音频期限、回拖无副作用、原子draw/read
GPU像素一致、取消、降级、原火焰/闪电/普通短斩回归及两个独立手机尺寸。
验证范围与具体结果见 `docs/qa/benchmark-sword-arts-r7.json`。
