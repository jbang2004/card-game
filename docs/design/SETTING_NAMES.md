## 一、先定标准：这个游戏的设定必须做到什么

设定不是装饰。对一个卡牌肉鸽来说，"最优"的设定要同时完成六件事：

1. **解释规则**：卡牌是什么、牌组为什么是一本书、为什么同名传说只能带一张、为什么衍生物不算数。玩家不读文字，也能从规则里感到世界是怎么运转的。
2. **解释循环**：为什么死了能重来、为什么每次下去地形都不同、为什么会遇到别的冒险者。
3. **制造取舍**：力量要有代价。代价会产生决策，决策就是深度。
4. **可以分层揭开**：真相一层层翻转，每次通关都能换来新的一层，让故事成为元进度的奖励。
5. **有情感核心**：玩家要在乎某样东西，而不只是"拯救世界"。
6. **可落地**：能复用现有 97 张插画、6 个首领战场和四位神的美术；名字原创，不像任何现有作品的山寨。

## 二、从《诡秘之主》学什么，不学什么

### 学它的原理

| 原理 | 在《诡秘之主》里 | 对我们的意义 |
|---|---|---|
| 力量体系就是世界观 | 超凡能力有明确的规则、来源和守恒律 | 设定要能从卡牌规则里推出来，而不是贴在规则外面 |
| 力量有代价 | 越强越接近失控，知识本身危险 | 远征里要有"为了变强而付出自己"的选择 |
| 守恒与唯一 | 力量不会消失只会转移，高位是有限的 | 解释卡牌掉落、传说唯一、诸神相争 |
| 神不可靠 | 正神也有私心和秘密交易 | 契约应该有隐藏代价，神应该有秘密 |
| 真相分层 | 历史被一层层掀开，每层颠覆上一层 | 元进度解锁真相 |
| 多重身份 | 主角以化名在不同场合行事 | 英雄用化名下潜，真名是秘密 |
| 日常与超凡的反差 | 蒸汽都市的报纸、工薪、街巷 | 上面有一座正常过日子的城，下面才是深渊 |
| 敬畏的仪式感 | 不可直呼高位存在，要用尊称 | 神只以尊称出现，真名是禁忌 |

### 不学它的具体设定

不用"途径""序列""魔药""扮演法""非凡特性""灰雾""塔罗会"这类专属体系与名词，也不做维多利亚蒸汽朋克外观。原因有三个：

- **观感**：照搬会一眼被认成同人或山寨。
- **机制不合**：魔药晋升是一条线性的个人成长线，和"组一副牌、打完就重开"的肉鸽循环对不上。
- **美术不合**：现有插画全是奇幻骑士、法师、野兽和神祇，换成蒸汽都市需要全部重画。

## 三、候选核心的比较

| 核心概念 | 解释规则 | 解释循环 | 代价取舍 | 分层真相 | 情感核心 | 可落地 |
|---|---|---|---|---|---|---|
| 余火（现行） | 弱：火和卡牌、印记没有必然关系 | 中 | 弱 | 中 | 弱："拯救世界"很泛 | 强 |
| 诡秘式神秘学（蒸汽都市 + 晋升体系） | 中 | 中 | 强 | 强 | 中 | **弱**：美术全换、山寨风险 |
| 梦境 / 戏剧 | 中 | 强 | 中 | 强 | 中 | 中，且"扮演"太接近诡秘 |
| **名（真名）** | **强** | **强** | **强** | **强** | **强** | **强** |

选"名"的理由在下一节：**现有规则已经在讲名字了**。

## 四、关键发现：规则早就在讲名字

下面这些现有规则都是之前各自独立设计出来的，放到一起看，它们说的是同一件事：

- 冥月神要"4 枚**不同名**的灵魂印记"，同名只算一次。
- 星焰神要"6 种**不同名**的法术"，重复的不算。
- **衍生物**（没有独立身份的召唤物）不留印记，也不计入任何仪式。
- 传说卡每副牌**只能带一张**，普通卡可以带两张。
- **沉默**让随从失去全部能力。**变形**让随从变成另一种东西。**潜行**让随从不能被指定。**嘲讽**逼对手先攻击它。
- 野兽**只有猎杀随从**才算狩猎，打英雄不算。

如果世界的根本法则是"**名字就是存在**"，以上每一条都有了理由，也就是第五节的五条律法。设定不再是贴上去的皮，而是从规则里长出来的。

## 五、世界的五条律法

**第一律 · 名即存在。** 万物因名字被记住而存在。一个名字被所有人彻底忘记，它指代的东西就会从世上消失，不留痕迹，连"曾经存在过"也一并消失。

**第二律 · 名不灭，只流转。** 名字不会被毁掉，只会离开。持名者死去，名字会离开身体，寻找下一个记得它的地方：神、生者，或者深渊。
→ 击败敌人后可以拿走它的名字（卡牌奖励）；击败首领可以拿走它的真名（传说奖励）。

**第三律 · 真名唯一。** 一个真名同一时间只能被一个存在持有。
→ 传说卡只能带一张；神要"不同名"的献祭；四大名之间有争夺。
→ 名有轻重：俗名（很多人共用，**普通**）、异名（**稀有**）、秘名（**史诗**）、真名（独一无二，**传说**）。**稀有度就是名字的重量。**

**第四律 · 无名者无重。** 没有名字的东西（回声、影子、临时凝成的形体）可以被召来，却不被世界计入：神不收，月不记。
→ 衍生物不留印记，不计入仪式。

**第五律 · 持名者，亦被名持。** 你借用的每个名字都压在你自己的名字上。借得越多、越重，你的本名就越薄。本名耗尽，你就会被你带着的名字改写，成为它们的容器。
→ 这是整个游戏的"代价"，对应诡秘里的失控，但落点在**身份**上：你不是疯了，而是不再是你。（第九节的「本名」机制）

## 六、宇宙与历史：四层真相

故事按四层揭开。每一层都会改写玩家对上一层的理解，由通关进度逐层解锁（第十一节）。

### 第一层（开局即知）：吞名者

鸣钟城的地底有一口井，井下是**名渊**，被遗忘之物沉积的地方。名渊最深处住着一个东西，城里人只叫它**「讳」**：不可说的那个。它吞食名字。被它吞掉的人和物，会从所有人的记忆里一起消失。

最近，天上的星星开始一颗接一颗消失，不是熄灭，而是**人们不再记得那里曾经有星**。只有观星人的旧星图上留着一个个空白的坐标。

你要下到名渊，逼讳把名字吐出来。

### 第二层（首次通关）：它不会死

打败讳，它吐出一批名字，几颗星重新出现在天上。但它没有死，只是沉回了更深处。你还在它的巢里发现了**守井人的誓约书**：守井人不是城里雇来的，而是四大名派来的。他们的职责不是挡住下面的东西，而是**挡住上面的人**。

### 第三层（四位英雄各自通关）：断名之约

四大名和讳之间有一份古老的契约，叫**断名之约**。每一代，四大名把一部分凡人的名字喂给讳，换它不吞神的名字。消失的星星、被吞掉的城区、那些"从来没有存在过"的人，都是祭品。

**断契监誓者**守的正是这份契约。它问你"付得起代价吗"，问的不是你，而是替神问的。神不是坏人，他们只是选择了保全自己，也保全了大多数人。这是诡秘式的"神不可靠"，但动机是可理解的。

### 第四层（真结局）：初忘之城

讳不是天生的怪物。鸣钟城建城时，城里的人对一个民族犯下了罪行，然后为了能安心活下去，**集体选择忘记**：他们抹掉了那个民族的名字、他们的城，以及这件事本身。四大名默许了。

被强行遗忘的名字不会消失（第二律），它们沉到井底，在黑暗里挨饿。千百年来，每一个被人刻意遗忘的名字都落进去，这股饥饿最终有了形体，就是讳。

它吞名字，是因为它自己就是**被遗忘的东西**，而它想被记住。

**真结局不是杀死它，而是唤出那个被遗忘的名字**：在第九层"初忘之城"，说出那个民族的名字。讳被命名的那一刻就不再饥饿，化作天上一颗新的星。

游戏名《唤名》的完整含义，要到这里才揭开。

### 为什么这个真相是对的

- **主题统一**：规则讲名字，结局也落在名字上。
- **情感成立**：遗忘在这里是一种罪。可以对应个人（为了不痛苦而忘记的人），也可以对应集体（被抹去的历史）。
- **四大名的角色被重新评价**：他们不是反派，而是共谋者，也是维持现状的人。
- **原创**：不是"创世神碎裂成众神"这类诡秘同款母题。

## 七、地理

**鸣钟城（地上）**：一座正常过日子的城。每天清晨，钟楼按户籍名册敲钟**点名**，钟声念到谁，谁就还在；黄昏再为死者敲一遍。城里有**当名铺**（拿名字的一部分换钱）、**噤名告示**（某些词禁止说出口）和**名窃**案件。这是诡秘式的日常与超凡反差，也是未来首页和活动的素材。

**寄名馆（中立之地）**：开在城边的旧酒馆，底下就是那口井。下潜的人都要在这里把**真名寄存**进馆主的名簿，换一个**化名**下去。原因很简单：讳只能吞有名字的东西，带着真名下去等于把自己送上餐桌。"寄名"本是民间习俗，指孩子认神佛作义亲以求庇佑，这里借用。
- 远征失败时，你的化名在深处碎掉，名簿上的真名把你拉回馆里，但会少一点东西（记忆、本名）。
- 远征中途的**酒馆**是馆主在名渊里的分店：挂着同一块招牌的门，出现在不同的层。

**名渊（地下八层）**：被遗忘之物沉积的地方。每一层都是某个失去名字的地方残留下来的记忆，所以**每次下去形状都不同**。这就是肉鸽的随机地图在设定里的解释。

| 层 | 地方 | 守在那里的失名者 |
|---|---|---|
| 1–2 | 弃名回廊 | **劲敌**：前人丢下的化名，被名渊驱动的空壳，也包括你自己上次倒下时丢下的化名 |
| 3–4 | 井门 / 低语林 | 守井人 · 荆棘女王 |
| 5–7 | 无光圣所 / 冻钟王座 / 月门 | 深渊先知 · 霜钟君王 · 断契监誓者 |
| 8 | 讳之巢 | 讳（以龙的形态出现） |
| 9（真结局） | 初忘之城 | 被遗忘的民族 |

讳没有固定形状，**它会变成那个时代的人最怕的东西**。这一代的人怕龙，所以它是龙。这个设定保留了现有的龙族美术，也给以后换形态留了口子。

## 八、四大名（众神）

神的真名也是讳，凡人只用**尊称**。他们的力量来自被呼唤：被越多人呼唤的名字就越重，最重的就成了神。所以神需要凡人，也愿意和凡人立约，只是有他们自己的算盘。

| 尊称 | 司掌 | 仪式（沿用现有规则） | 为什么是这个仪式 | 信众（职业） | 失名之影（首领） |
|---|---|---|---|---|---|
| **命星者** | 知识、群星。每颗星都是一个名字 | 说出 6 种**不同**的法术之名 | 他收集名字，重复的名字对他没有意义 | 命星院（法师） | **深渊先知**：想知道讳的真名，心智被吞 |
| **晨钟** | 守护、誓言。每天清晨点名，让生者确认自己还在 | 誓言被**敌人**敲响 4 次（圣盾被击破） | 钟要被敲才会响，誓言要被考验才算数 | 钟誓团（圣卫） | **霜钟君王**：为了不再失去任何名字，把钟和时间一起冻住 |
| **白角** | 生命、狩猎。林间万物的野名 | 野兽从**猎物**身上夺名 6 次 | 随从有名可夺；英雄的真名寄存在寄名馆，身上只有化名，**没有名字可夺**，所以打英雄不算狩猎 | 白角猎团（游侠） | **荆棘女王**：为了救一片森林，把森林的名字吞进自己身体，变成了森林 |
| **记名之月** | 死亡、记忆。收留死者的名字，不让讳吃掉 | 交出 8 个亡者、4 个**不同**的名字 | 月亮记的是名字，同名只记一次 | 提灯人（莫菈） | **断契监誓者**：守着断名之约的月门，只剩审判 |

现有神的立绘可以直接对应：星焰神 → 命星者，曙日神（日盾巨像）→ 晨钟，荒猎神（枝角、白毛）→ 白角，冥月神 → 记名之月。

**神律**（现有规则的解释）：
- 大名降临**不能直接攻击凡人英雄**，因为大名直接压在一个凡名上，那个名字会当场消失，世界承受不起。
- 神**每场只应一次**。
- 神**不能复生**：大名不会被月亮收留。

## 九、力量的代价：「本名」

这是本设定最重要的**机制提案**，对应诡秘最精彩的部分："力量有代价"。

- 每位英雄在寄名馆寄存的真名有若干个字，比如 5 个字，这就是**本名值**。界面上显示为英雄真名，但有几个字被墨迹遮住。
- **消耗本名**的事：
  - 收下**讳卡**：极强但带诅咒的卡，也就是深处被吞过的名字。
  - 让神降临：每次降临磨去 1 个字。
  - 阅读禁忌的**事件**：类似杀戮尖塔的诅咒之书，读了能知道真相，也会磨去字。
  - 失败时让馆主把你"多拉回来一次"：免死一次。
- **恢复本名**：在酒馆节点"念一遍自己的真名"，代价是放弃买牌或删牌。这借鉴了杀戮尖塔"在营火处回忆"的做法，但动机在我们的设定里自洽。
- **本名耗尽**：你被自己带着的名字改写，远征以"失名"结束。进阶版可以做成：失名后你成为下一次远征里的劲敌。

它产生的决策：要不要为了一张讳卡、一次神降，赌上自己？这就是诡秘式的张力，落在卡牌肉鸽最擅长的"风险换收益"上。

## 十、卡牌的在世释义

| 规则 | 在世界里 |
|---|---|
| 卡牌 | **名札**：写着一个名字的签。念出名字，名字的主人以回声的形态应召 |
| 牌组 | **名匣**：随身带下去的名札 |
| 法力（上限 10） | **息**：一口气能念出的音节是有限的。战斗越久，嗓子越开，最多十息 |
| 后手的以太硬币 | 一口**馆酒**：多一口气 |
| 英雄技能 | 英雄化名自带的本事 |
| 随从召唤后要等一回合 | 回声需要一回合凝成实体 |
| 冲锋 / 突袭 | 应声即动 |
| 嘲讽 | **报名**：高声自报名号，逼敌人先冲它来 |
| 潜行 | **匿名**：暂时藏起名字，不能被指名 |
| 圣盾 | **誓名**：一句誓言替它挡下一击 |
| 复生 | **回名**：月亮放回来一次 |

## 十一、人物

### 馆主

没有名字，也没有人问过。他的名簿记着所有下潜者的真名。他送人下去，看上去是为了阻止讳；到第四层真相才知道，他是**被遗忘民族的最后一人**，名簿里其实一直留着一页空白。他动机的真相由玩家自己判断：是想让有人把他族人的名字带回地面，还是想借你的手，让讳把整座城吞掉。

### 四位下潜者

现有的名字（艾莉娅、雷昂、薇丝珀、莫菈）正好成为他们在寄名馆登记的**化名**，真名随进度解锁。每个人下去，都是为了一个被吞掉的名字：

| 化名 | 身份 | 失去的名字 | 与之对照的失名者 |
|---|---|---|---|
| **艾莉娅** | 命星院观星人 | 她的星图上有一颗星的坐标是空的，旁边是她自己的笔迹："姐姐的星"。她想不起姐姐是谁 | 深渊先知：求知走到尽头会怎样 |

### 失名者（首领）

每个首领都是第五律的反面教材：借了太多、太重的名字，被改写的人。
- **守井人**（现"灰烬监守"）：四大名派来守井的人。守了太久，已经忘了自己在守什么，只记得"不许任何人下去"。
- **荆棘女王**、**深渊先知**、**霜钟君王**、**断契监誓者**：见第八节。
- **讳**：见第六节。

### 扩展包一的新卡，举例

- **星页书童**：命星院抄写名字的学徒。
- **霜晶傀儡**：额上刻着"守"字的冰构装。
- **熔核元素**：讳之裔。
- **盾誓侍祭 → 黎明大主教**：钟誓团的各级成员。
- **墓园守夜人、赤夜亡骑**：半名者。
- **白骨君主**：初忘之城的末代王，第四层真相的线索之一。
- **酒馆守誓人**：寄名馆替人保管名簿的伙计。

## 十二、远征与元进度

- **一次远征 = 一次下潜。** 胜一层，名渊吐出一点东西；倒下，化名碎在深处，你被名簿拉回寄名馆。
- **名录（元进度）**：图鉴里的「名录」随通关与事件逐条亮起，四层真相按第六节的条件解锁。故事就是奖励，这一点学的是杀戮尖塔二代的时间线。
- **事件节点（新增）**：地图上加"事件"，设定碎片藏在这里。有的要付本名才能读完。
- **首领真名（新增）**：击败首领后，宝物里可能出现它**堕落前**的真名传说卡（荆棘女王·未名之时……），同时补上游侠没有可收集传说的问题。
- **真结局**：在一次远征里带着四位大名的"信物"（各唤醒过一次神），打败讳之后开启第九层"初忘之城"。

## 十三、命名

### 游戏名

| 候选 | 含义 | 优点 | 缺点 |
|---|---|---|---|
| **《唤名》**（推荐） | 呼唤名字 | 就是"出牌"这个动作本身；真结局才揭开全部含义；搜索未见同名作品 | 字面偏平，需要副标题或美术帮忙 |
| 《寄名》 | 把名字托付出去 | 民俗词，有温度、有秘密感；对应寄名馆 | 需要解释；偏安静 |
| 《名渊》 | 名字的深渊 | 地点式命名，和《杀戮尖塔》同一路；搜索未见同名 | 略冷 |

英文名另议。注意：Namecaller 在英文里有"骂人"的意思，不宜使用。

### 命名规则

- **地名**：意义直白的汉字词（鸣钟城、寄名馆、名渊、初忘之城），不用音译。
- **神**：只用尊称（命星者、晨钟、白角、记名之月）。真名永远不写出来，它本身就是一个谜。
- **人名**：西式音译。人名在设定里本来就是化名，保持现有的艾莉娅、雷昂等，读起来有异域感。
- **称号·名**：保留给传说与首领的真名卡（逐日者·索拉）。
- 避免"烬、焰、鎏金"这类华丽装饰词。高频词汇集中在：名、讳、息、钟、灯、井、忘。

## 十四、对现有内容的影响

| 改动 | 类型 | 工作量 |
|---|---|---|
| 游戏名、首页文案、寄名馆取代鎏金酒馆 | 文案 | 小 |
| 神、首领、地点、部分卡牌改名（以太硬币 → 一口馆酒等） | 文案 + 数据 | 小 |
| 全部 97 张卡的短文（flavor）、首领半血与败北台词、英雄开场与结局 | 文案 + 新字段 | 中 |
| 词条的在世释义 | 文案 | 小 |
| 事件节点、名录元进度、首领真名奖励 | 规则 + 界面 | 中到大 |
| 「本名」代价系统、讳卡、第九层真结局 | 规则 + 界面 + 平衡 | 大 |
| 鸣钟城首页插画、寄名馆招牌与名簿 | 美术 | 中 |
| 卡牌插画 | 不需要重画 | — |

建议顺序：先定稿设定和名字（文案可以一次改完），再做事件与名录（把故事装进游戏），最后做本名系统。本名系统会改变平衡，要单独测试。

## 十五、需要拍板的问题

1. **核心概念**：用"名"作为世界的根本法则吗？
2. **游戏名**：《唤名》《寄名》《名渊》，或者由这个方向再想。
3. **第四层真相**：鸣钟城建城时抹去一个民族，讳是被强行遗忘的饥饿。它有明确的道德分量，你能接受这个基调吗？
4. **馆主**：真结局时保持动机模糊，还是给出明确答案？
5. **本名系统**：要不要做？它会让游戏明显更有张力，也更难。
