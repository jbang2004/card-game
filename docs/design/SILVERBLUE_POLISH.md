2026-09-12，在既有银蓝表现层上完成逐页细节审查。三个子代理分别处理桌面工作区、次级弹窗和手机布局；主代理负责战斗界面、合并后跨尺寸评审、返工及最终验收。未新增美术素材，未修改内容、规则、AI 或存档格式，未发布。

## 逐项处理

| 页面 | 发现的问题 | 最终处理 |
| --- | --- | --- |
| 首页 | 明亮背景上的辅助小字难读，横屏入口节奏松散 | 增强小字对比，整理标题、说明和操作的先后关系 |
| 桌面英雄 | 右栏留白过散，768 高窗口主要配置落入下方 | 套牌与模式并列，统一分组间距与曲线样式 |
| 手机英雄 | 横屏头像选项继承卡片比例，四位英雄显示不全 | 普通横屏四行，短横屏 2×2；头像与选择状态完整可见 |
| 平板英雄 | 沿用了手机的顶部留白，主按钮拆行 | 档案上移，设置独立按钮比例，保留单行主行动 |
| 桌面收藏 | 窄窗口卡片过密，卡牌徽章挤到操作行 | 1024/1366/1600 分别 3/4/5 列，宽屏卡宽封顶 232px，增加操作净距 |
| 手机收藏 | 常驻筛选占满短屏，内层滚动窗只能看见卡图上沿 | 短屏改整页滚动，标题和筛选随内容滑走；完整卡片与操作可同屏阅读 |
| 牌组编辑 | 按钮换行不齐，费用与曲线残留旧配色 | 主次操作分行对齐，使用当前主题变量；搜索和草稿往返保留 |
| 地图 | 标题、节点、档案比例不一致 | 统一标题与边距，窄桌面节点收紧，手机保留专用排列 |
| 战斗 | 左栏高度仅 61px、路线溢出，首领文案越界 | 两侧栏自持尺寸，路线内部滚动，正文和分隔线重新对齐 |
| 法力与反馈 | 法力图标分两行，固定提示高度与实际文字不符 | 水晶统一一行；提示按实际换行高度定位 |
| 设置 | 分组顶端错位，短横屏标签挤成单字 | 左右分组对齐，短横屏改两列，保留完整可滚动控制 |
| 手册 | 关键词旧深褐文字不可读，横屏目录占去正文空间 | 统一浅色正文；横屏目录与正文分栏，章节间距清晰 |
| 契约、换牌、奖励、结算、详情 | 旧金线/外框、局部间距不统一 | 统一细线、说明与操作层级；奖励规则保持至少 16px |
| 共用滚动提示 | 提示渐层压住最后一行文字或曲线 | 提示独占 22px 行，到底隐藏但保留位置，避免跳动 |

## 组织方式

新增四个按职责划分的细节样式文件，注册在现有 `components` 层中，顺序为桌面工作区、通用弹窗、战斗、手机：

- `src/presentation/polish-desktop.css`：桌面首页、英雄、收藏、地图。
- `src/presentation/polish-dialogs.css`：弹窗材质、阅读与滚动提示。
- `src/presentation/polish-battle.css`：战斗侧栏、法力和文字节奏。
- `src/presentation/polish-mobile.css`：手机与平板专用布局。

颜色与材质继续引用 `components.css` 的语义变量。布局精修不引入新的硬编码配色，不改变 Canvas 与交互平面的坐标契约。仅 `src/ui.js` 增加一次提示文字高度测量，避免固定高度假设随主题失效。旧兼容样式仍存在，本轮没有顺便重写规则或删除现役布局基础。
