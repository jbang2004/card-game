# 高识别度卡牌插画方向

本轮素材采用统一的“移动端策略卡牌”绘制语言：大形清晰、主体居中、边缘利落、低纹理密度、单一核心动作；卡图必须在 64px 高度分辨人物/道具/法术事件。卡名、费用、攻血、规则与卡框继续由 DOM 负责，不烘焙进原画。

## 统一规则

- 一张图只保留一个主角、武器、道具或法术事件；不使用复杂远景、细密花纹、粒子云与多重焦点。
- 人物/生物占画面约 70%；法术/道具保留足够负空间；背景只支持轮廓，不参与叙事。
- 材质使用干净金属、布料、石材和能量面，保留轻量的 3D 动漫感与硬边高光。
- 同一阵营不能依靠复制背景区分卡片；每张卡用姿态、道具或事件主形区分。

## 神卡

神卡采用低机位、主体高度超过画面 80%、环境尺度明确的小人/建筑/山脉参照物。每位神有独立天象：瑟弥拉的月蚀海、烬辰的星核熔火、奥瑞恩的日轮天阶、芬洛斯的巨树与群兽。宏大来自尺度与留白，不来自堆叠粒子。

## 无框满幅卡面与属性宝石（v7，2026-09-14 起）

- 新卡没有任何外框：既不用整圈金属边，也不再用半包围悬浮铭牌与两枚晶体铆钉（均已删除）。原画从卡的上沿满幅铺到 60%，与下半深色面板一起构成卡的边界；圆角就是卡的轮廓（卡宽的 3.6%）。原画下沿用一段渐变淡入面板，四角另加暗角，保证卡名与规则永远压在暗部上。
- 阵营由**名牌胶囊**承担：卡名是一枚骑在 56.8% 处、跨在原画与面板交界上的胶囊，描边取阵营色（奥术蓝 / 金白 / 森林绿 / 冥月紫 / 中立钢 / 烬火橙），规则里的关键词用同一色并带 16×16 遮罩图标。
- 稀有度由**卡底金属带**承担，而不是外框：卡底一条抛光金属条，刻「类型 · 职业」（部落不上带，三段放不下），金属配色为 common 钢 / rare 冰蓝 / epic 紫晶 / legendary 金，传说另加一圈暖色外光。卡号 `EMBERFALL · No.NNN` 以极小等宽字压在金属带上方。
- 卡名、规则、类型、卡号继续是实时 DOM。任何页面（手牌、收藏、详情、换牌、发现、战场）必须调用同一张卡组件，不能为某个页面烘焙带字图片。
- 属性徽章改为「形状即含义」的宝石（`EmberArt.statGem`）：攻击是交叉双剑压一枚琥珀菱晶，生命是红宝石心晶，武器耐久是青晶盾；三者钢圈包边、面积等视觉重量，悬在卡的左下 / 右下角外侧。费用是一枚纯 CSS 的烟熏玻璃圆盘嵌细钢圈，落在左上角外侧。数值始终保持实时文字，不嵌入图标。
- 战场随从使用同一套语法的「战场态」：满幅原画 + 稀有度金属带 + 两枚宝石，不显示卡名与规则，不加外框；嘲讽 / 圣盾 / 冻结 / 可攻击 / 可指定等状态改为原画外圈的彩色环与光晕。
- 战场英雄和随从以其 v4 静态原画进行克制的镜头漂移。动态画布不得重新显示已退役的旧分层原画；降低动态时直接显示同一张 v4 静态图。
