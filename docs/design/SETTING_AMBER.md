## 〇、一句话与三十秒

**一句话**：一个人为了找回死去的妻子，挖穿了世界；另一个世界里，失去丈夫的她，也在往下挖。

**三十秒**：
> 三千年前，诸神挖到世界树的根部，撞上了另一个世界。灭世之战几乎抹去了一切生灵，世界树流下树脂，把战死者一个个封进琥珀。幸存的火种立下禁令"不可掘根"，把琥珀代代供奉。
>
> 四十年前，一个穷机修工的儿子造出了琥珀蒸汽机，人称"点火者"。他用短短几十年建起一个庞大的联邦，告诉所有人往深处挖是为了更多的琥珀、更好的生活。真正的原因只有他自己知道：他要穿过世界树的根，去另一个世界找他死去的妻子。
>
> 如今他已经站在根部，只差五位神的力量就能打开那扇门。其中四块神之琥珀，就在你们四个人身上。

**主题：保存与放手。** 琥珀是保存，而每一个重要人物，都是对"该留住什么、该放下什么"的不同回答。

## 一、世界结构：双树双界

```
        我们的天空（世界树的枝冠，群星是它发光的叶）
                 │
             【世界树 · 长青】        琥珀之界（我们的世界）
                 │  树根向下
    ═══════════ 根 海 ═══════════   两棵树的根在此缠结，是两界唯一的边界
                 │  树根向"下"
             【黑玉之树】              黑玉之界（另一个位面）
                 │
        它们的天空（黑玉之树的枝冠，暗紫色的天，黑色的星）
```

- **两界互为倒影**：大陆轮廓相反，住着"同样"的人，各自的命运不同。黑玉之界的文字是镜像书写的。
- **两边都管自己的树叫"长青"**，管对方的叫"黑树"。在他们眼里，我们才是黑暗那一边。
- **根海**是两棵树根须缠结的地方。挖到根海，就是在两个世界之间凿洞。

| 时代 | 距今 | 发生了什么 |
|---|---|---|
| **神话时代** | 三千年以前 | 神、人、野兽与各种神话生物共存。五位神各司一域 |

| **火种纪元** | 三千年间 | 幸存的一小撮人重建文明，封死根部通道，立下"不可掘根"。长青教会成立。琥珀被各家各户代代供奉 |
| **蒸汽纪元** | 最近四十年 | 纳坦·布兰特发明琥珀蒸汽机，布兰特联邦崛起，琥珀成为最值钱的商品。十二年前，他的妻子伊芙病逝；此后，大竖井越挖越深 |

**根战后留下了什么**：
- 我们这一边的战死者被世界树的树脂封进**琥珀**；另一边的战死者，被焦黑的树干化成的**黑玉**封住。
- 五位神也在战中陨落。其中四块**神之琥珀**落在我们这一边。第五位神"炉母"跌过了边界，化作一条沉睡在根海的**黑玉之龙**。她有一小块琥珀碎片留在了这一边，四十年前被纳坦捡到。

**教会隐瞒的真相〔默认〕**：长青教会三千年来一直教导人们，灾难来自"地底的黑暗"。它隐瞒了最关键的一点：**第一次掘根的，是诸神自己**。

## 三、琥珀与黑玉

**琥珀是什么**：世界树的眼泪。每一块琥珀里，都封着一个在根战中战死的远古生命，是某一瞬间被凝固的它。
- 大多数琥珀里是生灵：骑士、法师、野兽、巨人。
- 有的琥珀封住了一道咒术：一颗正在坠落的陨星、一阵寒潮。
- 有的封住了一件兵器。

**怎么唤醒**：把琥珀焐热，里面的生命就会醒来片刻，为持有者而战。战斗结束，它会回到琥珀里沉睡，而不是死去。唤醒琥珀的温度，来自持有者体内的**火种**。

**琥珀的文化**：
- **火种纪元**：琥珀是家族的祖传圣物，供在家中神龛上。只有在生死关头，才会请出来作战。
- **蒸汽纪元**：琥珀变成了燃料和商品。旧家族变卖祖传琥珀，矿工越挖越深，因为越深的地层越古老，琥珀的力量越强。教会斥之为"焚烧先人"，但拦不住。

**黑玉**是另一边的"琥珀"。黑色、冰冷，封着另一边的战死者。靠近根海的地方，黑玉会渗进这一边，侵蚀活人和琥珀。**黑玉可以被火种焐化，净化成琥珀**。

神的真名在火种纪元就失传了，人们只用尊称。

| **执盾者** | 太阳、誓约 | 由菲德莉亚携带（原属联邦总工近卫） | 圣盾被敌人击破 4 次 | 誓言要在挨打时守住才算数 |
| **白角** | 荒野、狩猎。白色的狼狮，头生金角 | 林中村落的圣龛，由罗温携带 | 野兽猎杀敌方随从 6 次 | 他只认真正的狩猎 |

**五神的力量能打开根海，也能封住根海。谁握着五神，谁决定。** 这就是全剧的争夺核心：纳坦要开门，世界树要关门，而四块钥匙就在主角身上。

**神律（现有规则的解释）**：
- 神之琥珀只能苏醒片刻，一场战斗一次。
- 神不对凡人英雄出手。
- 神醒过一次需要长久休养，所以不能复生。

**为什么四位主角和神相像**：守护神之琥珀的家族，大多是当年神的凡人战友的后裔，血脉里留着神的样子。现有神与英雄立绘的相似可以成为伏笔（对照图：[img/hero-god-resemblance.jpg](img/hero-god-resemblance.jpg)）。

## 六、选角原则

这一节说明人物为什么这样设计，以后新增人物也按它来。

1. **名字要有来历**：有词源、有反讽或双关，同一文化的名字发音统一。不随手音译。
2. **每个人都有一个核心矛盾**，并且是对主题"保存与放手"的一种回答。
3. **每个人都有一个视觉钩子**：一眼能记住的物件或特征。
4. **人物之间有关系网**：主角与反派一家互相牵连，而不是各自独立的"工具人"。
5. **次要敌人用称号，不用人名**：参照杀戮尖塔的"收藏家""时间吞噬者"，"铁哨""引信"比"格伦""莉塔"好记，也更有故事。
6. **名字与立绘一致**：性别、年龄、气质都对得上。
7. **避开知名作品里同名同设定的角色**。

**一个彩蛋**：纳坦（NATAN）、伊芙（EVE）、艾达（ADA）三个名字都是回文。黑玉之界的文字是镜像书写的，只有他们一家的名字，在两个世界里读起来一模一样，就像他们在两边都是同一家人。

## 七、人物

### 四位主角（持琥珀者）

每一局远征选一人。四人奉教会之命，从不同的路线下井。真结局要求四人都走到根海。

| 主角 | 立绘 | 身份 | 视觉钩子 | 核心矛盾 | 与纳坦 |
|---|---|---|---|---|---|
| **娜希拉**（女） | 银发、藏蓝长袍、星盘 | **鉴珀师**：用星盘读出琥珀里封着的年代与生命，曾为联邦的琥珀登记处编目 | 能透视琥珀的星盘 | 她保存知识，可她编的目录，让联邦烧琥珀烧得更有效率 | 纳坦资助了她的天文台，她曾视他如父 |
| **菲德莉亚**（女） | 金发女骑士、日纹盾 | **背誓的骑士**：曾任总工近卫队长，守护纳坦一家，也是艾达的护卫 | 刮掉了联邦徽记的日盾 | 名字的意思是"忠诚"，她却背弃了誓言，为了守住一个更大的誓言 | 纳坦下令封死一座塌方的矿井以继续掘进，她当场叛离 |
| **罗温**（男） | 黑发青年、绿斗篷、长弓 | **最后的守林人**：林中村落的猎人，村子的圣龛里供着白角之琥珀 | 箭袋里插着一截花楸枝 | 他想猎杀联邦的人，可白角只认对野兽的狩猎 | 纳坦的露天矿剥光了他的森林 |
| **利奥尔**（男） | 银发、白披风、提灯 | **提灯人**：月神殿为亡者引路的人 | 他的灯里装着双胞胎妹妹利奥拉的灵魂 | 他劝所有人放手，自己却放不下妹妹 | 利奥拉死在大竖井的矿难里。他是整部作品里最像纳坦的人，也是唯一能让纳坦放手的人 |

名字的含义：
- **娜希拉**：一颗星的名字，意为"带来好消息的人"。
- **菲德莉亚**：意为"忠诚"。
- **罗温**：花楸树，民间传说里驱邪护家的树。
- **利奥尔、利奥拉**：意为"我的光"，一对只差一个字母的双胞胎名字。

### 纳坦·布兰特（最终首领）

- **称号**："点火者"。他拒绝称王，坚持让人叫他"总工程师"。
- **名字**：纳坦意为"他给予"：他给了世界火。布兰特源自"火、燃烧"。
- **出身**：穷机修工的儿子。少年时在废矿里捡到一块发烫的琥珀碎片（炉母的碎片），以此造出第一台琥珀蒸汽机。
- **崛起**：四十年间，从作坊到公司，从公司到联邦。
- **公开的面目**：进步、富足、"让每个人都用得起琥珀的光和热"。很多人真心追随他。
- **真正的伤**：妻子伊芙死于"炉肺病"，也就是工厂的煤烟与琥珀烟尘。**杀死她的，是他自己的发明。**
- **真正的目的**：伊芙死后，他从教会封存的书库里得到火种纪元的古籍《根海手札》，上面写着"诸神下至根海，见彼界之神"。他认定死者去了另一边。此后十二年，大竖井日夜不停。
- **视觉钩子**：一只永远停在伊芙去世那一刻的怀表。
- **现在**：他站在根海边，身旁是沉睡的黑玉之龙。他不恨你们，他只是在等你们把钥匙送来。

### 纳坦的家人

- **伊芙**（这一边）：温柔、爱种花，死于炉肺病。名字意为"生命"。只存在于纳坦的怀表、日记和回忆里。
- **伊芙**（另一边）：在黑玉之界，死去的是纳坦，活下来的是她。她接过了丈夫的事业，也读到了同样的古籍，于是从另一边往下挖。从地底涌上来的"黑暗战士"，是她的人。
- **艾达**：纳坦与伊芙的女儿，天才工程师，总工近卫的现任统领。她想要回来的不是母亲，而是父亲。菲德莉亚曾是她的护卫，像她的姐姐。名字向历史上工程世家的女儿、第一位程序员艾达·洛芙莱斯致敬。

### 其他

- **阿玛拉**：铜壶酒馆的老板娘。四十年前，纳坦的第一台原型机意外焐化了一块琥珀，从里面走出来的就是她：**一个三千年前根战时代的人**。她是"琥珀里封着真人"的活证据，也知道根战的真相。当年她无意中对纳坦说过"诸神去了另一边"，所以开这家酒馆，一半是为了赎罪。她承担炉石店主那样的角色：新手引导、开包时的欢呼、远征出发前的一句话。名字意为"不凋零"。
- **大修枝人**：长青教会的领袖，本名不为人知。真心想拯救世界，也真心想守住教会的秘密。"修枝"既指照料世界树，也指修剪历史。

## 八、主线

**序章**（首次进入游戏）：地震。大竖井里涌出黑玉的影子。教会召集四位持琥珀者，阿玛拉的酒馆成了出发点。

**第一幕 · 联邦矿区**（第 1–3 层）：下井，与联邦的监工、爆破手、掘进机交手。发现矿工大量死亡，死亡名单被掩盖。

**第二幕 · 古代地层**（第 4–5 层）：进入火种纪元的遗迹与联邦研究站。发现联邦在研究黑玉，强行砸开古老的琥珀。得知总工程师要找的不是琥珀，而是"门"。

**第三幕 · 神话战场**（第 6–7 层）：根战的遗迹。遇见被逼疯的根母、守在边界的守灯之兽、率领近卫的艾达，以及**自己的镜影**：另一边的持琥珀者，同样奉他们教会之命，来阻止"从地底涌上来的黑暗"。

**终章 · 根海**（第 8 层）：纳坦驾驶蒸汽机甲迎战。机甲被击破后，他唤醒了黑玉之龙，也就是炉母。

**结局**：
1. **封根**（普通通关）：击败纳坦，用五神重新封住根海。纳坦死在根海边，手里握着停走的怀表。如果主角是利奥尔，他会为纳坦提灯，也放走了自己的妹妹。
2. **镜中人**（真结局，四位主角各通关一次后开启）：第九层，穿过根海，走进黑玉之界。另一边的伊芙与纳坦隔着根海相见。他们终于明白，彼此都不是自己失去的那个人，只是爱人的倒影。两人选择一起留在根海，成为新的封印。**爱打开的门，由爱来关上。** 四位主角与他们的镜影告别，两个世界之间留下了一扇可以敲的门，这是未来扩展包去往另一边的入口。

**揭示顺序（元进度）**：

| 进度 | 揭开什么 |
|---|---|
| 第一次通过第一幕 | 联邦在掩盖矿难 |
| 第一次通过第二幕 | 总工程师要找的是"门" |
| 第一次遇见镜影 | 黑暗战士是另一个世界的人 |
| 第一次通关 | 伊芙与《根海手札》 |
| 四人各通关一次 | 教会隐瞒的根战真相；阿玛拉的来历；另一边的伊芙 |
| 真结局 | 全部 |

- **每层二选一**：竖井里的岔路。
- **中途的酒馆**（第 2、4、6 层）：火种纪元封根时留下的地下礼拜堂，教会把它们改成了补给站。
- **失败**：神之琥珀护主，把倒下的持有者拉回地面，但带下去的琥珀都留在了井下，会落到"典当人"手里。
- **战后挑卡**：从击败的联邦士兵身上缴获琥珀，或把击败的黑玉战士净化成琥珀。
- **地形每次不同**：竖井不断坍塌改道，根须在蠕动。

## 十、敌人体系

**战斗形式**：保留双方对称出牌（双方都有英雄、法力、手牌、随从），这是现有规则、AI 和 3D 战场的核心。

**做法参照炉石"地下城冒险"**：每个对手由称号、立绘、专属英雄技能、一条被动规则、一套主题卡组（现有卡池加 1–3 张专属卡）构成。

**借鉴杀戮尖塔的"意图预告"**：精英与首领的大招提前一回合显示，玩家可以提前应对。

## 十一、卡牌在世界里是什么

| 规则 | 解释 |
|---|---|
| 卡牌 | 一块琥珀，里面封着一个远古生命、一道咒术或一件兵器 |
| 牌组 | 随身的琥珀匣 |
| 法力（每回合 +1，上限 10） | 持有者的**火种**之温：体温一点点升起，最多焐热十分 |
| 以太硬币 → **琥珀碎片** | 一小片琥珀，多给一分温度 |
| 召唤后要等一回合 | 琥珀复苏需要时间 |
| 随从阵亡，下一场又能用 | 它退回了琥珀，而不是死去 |
| 衍生物不留灵魂、不计入仪式 | 它们是琥珀力量的投影，不是生命 |
| 传说卡只能带一张 | 远古英雄的琥珀独一无二 |
| 神的契约不进牌组 | 神之琥珀由持有者贴身携带，只能靠仪式唤醒 |
| 沉默 | 把它的力量重新封回琥珀里 |
| 冻结 | 像被封进琥珀一样凝住 |
| 奥秘 | 暗藏的琥珀，条件满足时自己苏醒 |
| 亡灵 | 被黑玉侵蚀的生命 |
| 龙 | 炉母的余裔 |
| 构装体（石像、泰坦） | 联邦的蒸汽傀儡与发条兵 |
| 遗物 | 根战遗留的器物 |
| 金币、买牌、删牌 | 联邦马克，在补给站买卖琥珀 |
| 练习对战 | 铜壶酒馆里用仿制琥珀打的牌局，输了只输一杯酒 |

**现有传说卡的身份**：
- **逐日者·索拉**：根战中执盾者麾下的骑士。
- **星陨女王·妮克丝**：根战时代的星之女王。
- **白霜之王**：根战英雄，战后把自己冻在井中守根，就是"守根人"。
- **终焰·阿什拉**：改名"炉母的余烬"，就是纳坦引擎的核心碎片。
