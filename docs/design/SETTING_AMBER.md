## 〇、一句话与三十秒

**一句话**：一个人为了找回死去的妻子，挖穿了世界；另一个世界里，失去丈夫的她，也在往下挖。

**三十秒**：
> 三千年前，诸神挖到世界树的根部，撞上了另一个世界，灭世之战几乎抹去了一切生灵。世界树流下树脂，把战死者一个个封进琥珀。幸存的火种立下禁令"不可掘根"，把琥珀代代供奉。
>
> 四十年前，发明家奥托·布伦纳造出了琥珀蒸汽机，用短短几十年建起一个庞大的联邦。他告诉所有人，往深处挖是为了更多的琥珀、更好的生活。真正的原因只有他自己知道：他要穿过世界树的根，去另一个世界找他死去的妻子。
>
> 如今他已经站在根部，只差五位神的力量就能打开那扇门。其中四块神之琥珀，就在你们四个人身上。

## 一、世界结构：双树双界

```
        我们的天空（世界树的枝冠，群星是它发光的叶）
                 │
             【世界树 · 长青】        琥珀之界（我们的世界）
                 │  树根向下
    ═══════════ 根 海 ═══════════   两棵树的根在此缠结，是两界唯一的边界
                 │  树根向"下"
             【黑玉之树】              黑玉之界（另一个位面）
                 │
        它们的天空（黑玉之树的枝冠，暗紫色的天，黑色的星）
```

- **两界互为倒影**：大陆轮廓相反，住着"同样"的人，各自的命运不同。黑玉之界的文字是镜像书写的。
- **两边都管自己的树叫"长青"**，管对方的叫"黑树"。在他们眼里，我们才是黑暗那一边。
- **根海**是两棵树根须缠结的地方。挖到根海，就是在两个世界之间凿洞。

**根战后留下了什么**：
- 我们这一边的战死者被世界树的树脂封进**琥珀**；另一边的战死者，被焦黑的树干化成的**黑玉**封住。
- 五位神也在战中陨落。其中四块**神之琥珀**落在我们这一边。第五位神阿什拉跌过了边界，化作一条沉睡在根海的**黑玉之龙**。它有一小块琥珀碎片留在了这一边，四十年前被奥托捡到。

**教会隐瞒的真相〔默认〕**：长青教会三千年来一直教导人们，灾难来自"地底的黑暗"。它隐瞒了最关键的一点：**第一次掘根的，是诸神自己**。

## 三、琥珀与黑玉

**琥珀是什么**：世界树的眼泪。每一块琥珀里，都封着一个在根战中战死的远古生命，是某一瞬间被凝固的它。
- 大多数琥珀里是生灵：骑士、法师、野兽、精灵、巨人。
- 有的琥珀封住了一道咒术：一颗正在坠落的陨星、一阵寒潮。
- 有的封住了一件兵器。

**怎么唤醒**：把琥珀焐热，里面的生命就会醒来片刻，为持有者而战。战斗结束，它会回到琥珀里沉睡，而不是死去。唤醒琥珀的温度，来自持有者体内的**火种**。

**琥珀的文化**：
- **火种纪元**：琥珀是家族的祖传圣物，供在家中神龛上。只有在生死关头，才会请出来作战。
- **蒸汽纪元**：琥珀变成了燃料和商品。旧家族变卖祖传琥珀，矿工越挖越深，因为越深的地层越古老，琥珀的力量越强。教会斥之为"焚烧先人"，但拦不住。

**黑玉**是另一边的"琥珀"。黑色、冰冷，封着另一边的战死者。靠近根海的地方，黑玉会渗进这一边，侵蚀活人和琥珀。**黑玉可以被火种焐化，净化成琥珀**。

**五神的力量能打开根海，也能封住根海。谁握着五神，谁决定。** 这就是全剧的争夺核心：奥托要开门，世界树要关门，而四块钥匙就在主角身上。

**神律（现有规则的解释）**：
- 神之琥珀只能苏醒片刻，一场战斗一次。
- 神不对凡人英雄出手。
- 神醒过一次需要长久休养，所以不能复生。

**为什么四位主角长得像神**：守护神之琥珀的四个家族，都是当年神的凡人战友的后裔。血脉里带着神的样子，这也是神的琥珀只认他们的原因。现有神的立绘与英雄立绘的相似正好成为伏笔（对照图：[img/hero-god-resemblance.jpg](img/hero-god-resemblance.jpg)）。

### 奥托·布伦纳（最终首领）

- **出身**：穷机修工的儿子。少年时在废矿里捡到一块发烫的琥珀碎片（火神阿什拉的碎片），以此造出第一台琥珀蒸汽机。
- **崛起**：四十年间，从作坊到公司，从公司到联邦。他拒绝称王，坚持让人叫他"**总工程师**"。
- **公开的面目**：进步、富足、"让每个人都用得起琥珀的光和热"。很多人真心追随他。
- **真正的伤**：妻子莉赛尔死于"炉肺病"，也就是工厂的煤烟与琥珀烟尘。**杀死她的，是他自己的发明。**
- **真正的目的**：莉赛尔死后，他从教会封存的书库里得到一部火种纪元的古籍《根海手札》，上面写着"诸神下至根海，见彼界之神"。他认定死者去了另一边。此后十二年，大竖井日夜不停。
- **现在**：他站在根海边，身旁是沉睡的黑玉之龙。他不恨你们，他只是在等你们把钥匙送来。

### 莉赛尔（两个）

- **这一边的莉赛尔**：温柔、爱笑、喜欢种花，死于炉肺病。她只存在于奥托的回忆、怀表里的照片和他的日记里。
- **另一边的莉赛尔**：在黑玉之界，死去的是奥托，活下来的是她。她接过了丈夫的事业，也读到了同样的古籍，于是从另一边往下挖。从地底涌上来的"黑暗战士"，是她的人。

### 其他

- **缇娅**：铜壶酒馆的精灵老板娘。她还记得联邦之前的年代，爱讲古老的传说，是教会在井边的联络人。她可以承担炉石店主那样的角色：新手引导、开包时的欢呼、远征出发前的一句话。
- **大主祭**：长青教会的领袖。真心想拯救世界，也真心想守住教会的秘密。
- **卡特琳娜·布伦纳**：奥托与莉赛尔的女儿、联邦近卫统领。她想要回来的不是母亲，而是父亲。

## 七、主线

**序章**（首次进入游戏）：地震。大竖井里涌出黑玉的影子。教会召集四位持琥珀者，缇娅的酒馆成了出发点。

**第一幕 · 联邦矿区**（第 1–3 层）：下井，与联邦的监工、爆破手、骑警交手。发现矿工大量死亡，死亡名单被掩盖。

**第二幕 · 古代地层**（第 4–5 层）：进入火种纪元的遗迹与联邦研究站。发现联邦在研究黑玉，强行砸开古老的琥珀。得知总工程师要找的不是琥珀，而是"门"。

**第三幕 · 神话战场**（第 6–7 层）：根战的遗迹。遇见被逼疯的根须守护灵、守在边界的神兽。遇见**自己的镜影**：另一边的持琥珀者，同样奉他们教会之命，来阻止"从地底涌上来的黑暗"。

**终章 · 根海**（第 8 层）：奥托驾驶蒸汽机甲迎战。机甲被击破后，他唤醒了黑玉之龙阿什拉。

**结局**：
1. **封根**（普通通关）：击败奥托，用五神重新封住根海。奥托死在根海边，手里握着莉赛尔的怀表。莫菈可以为他提灯，让他看见妻子早已安然渡过了月亮。
2. **镜中人**（真结局，四位主角各通关一次后开启）：第九层，穿过根海，走进黑玉之界。另一边的莉赛尔与奥托隔着根海相见，他们终于明白，彼此都不是自己失去的那个人，只是爱人的倒影。两人选择一起留在根海，成为新的封印。**爱打开的门，由爱来关上。** 四位主角与他们的镜影告别，两个世界之间留下了一扇可以敲的门，这是未来扩展包去往另一边的入口。

**揭示顺序（元进度）**：

| 进度 | 揭开什么 |
|---|---|
| 第一次通过第一幕 | 联邦在掩盖矿难 |
| 第一次通过第二幕 | 总工程师要找的是"门" |
| 第一次遇见镜影 | 黑暗战士是另一个世界的人 |
| 第一次通关 | 奥托的妻子与《根海手札》 |
| 四人各通关一次 | 教会隐瞒的根战真相；另一边的莉赛尔 |
| 真结局 | 全部 |

## 九、敌人体系

**战斗形式**：保留双方对称出牌（双方都有英雄、法力、手牌、随从），这是现有规则、AI 和 3D 战场的核心。

**做法参照炉石"地下城冒险"**：每个对手由名字、立绘、专属英雄技能、一条被动规则、一套主题卡组（现有卡池加 1–3 张专属卡）构成。

**借鉴杀戮尖塔的"意图预告"**：精英与首领的大招提前一回合显示（例如"下回合：钻头过热，对你所有随从造成 4 点伤害"），玩家可以提前应对。

## 十、卡牌在世界里是什么

| 规则 | 解释 |
|---|---|
| 卡牌 | 一块琥珀，里面封着一个远古生命、一道咒术或一件兵器 |
| 牌组 | 随身的琥珀匣 |
| 法力（每回合 +1，上限 10） | 持有者的**火种**之温：体温一点点升起，最多焐热十分 |
| 以太硬币 → **琥珀碎片** | 一小片琥珀，多给一分温度 |
| 召唤后要等一回合 | 琥珀复苏需要时间 |
| 随从阵亡，下一场又能用 | 它退回了琥珀，而不是死去 |
| 衍生物不留灵魂、不计入仪式 | 它们是琥珀力量的投影，不是生命 |
| 传说卡只能带一张 | 远古英雄的琥珀独一无二 |
| 神的契约不进牌组 | 神之琥珀由家族世代携带，只能靠仪式唤醒 |
| 沉默 | 把它的力量重新封回琥珀里 |
| 冻结 | 像被封进琥珀一样凝住 |
| 奥秘 | 暗藏的琥珀，条件满足时自己苏醒 |
| 亡灵 | 被黑玉侵蚀的生命 |
| 龙 | 阿什拉的余裔 |
| 构装体（石像、泰坦） | 联邦的蒸汽傀儡 |
| 遗物 | 根战遗留的器物 |
| 金币、买牌、删牌 | 联邦马克，在补给站买卖琥珀 |
| 练习对战 | 铜壶酒馆里用仿制琥珀打的牌局，输了只输一杯酒 |

**现有传说卡的身份**：
- **逐日者·索拉**：根战中日神麾下的骑士。
- **星陨女王·妮克丝**：根战时代的星之女王。
- **白霜之王**：根战英雄。战后他没有进琥珀，而是把自己冻在井中守根，就是"封根守誓者"。
- **终焰·阿什拉**：火神的碎片，也就是奥托引擎的核心。
