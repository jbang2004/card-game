## 〇、一句话与三十秒

**一句话**：一个人为了找回死去的妻子，挖穿了世界；另一个世界里，失去丈夫的她，也在往下挖。

**三十秒**：
> 三千年前，诸神挖到世界树的根部，撞上了另一个世界。灭世之战几乎抹去了一切生灵，世界树流下树脂，把正要倒下的人一个个封进琥珀。幸存的火种立下禁令"不可掘根"，把琥珀代代供奉。
>
> 四十年前，一个穷机修工的儿子造出了琥珀蒸汽机，人称"点火者"。他用短短几十年建起一个庞大的联邦，告诉所有人往深处挖是为了更多的琥珀、更好的生活。真正的原因只有他自己知道：他要穿过世界树的根，去另一个世界找他死去的妻子。
>
> 如今他已经站在根部，只差五位神的力量就能打开那扇门。其中四块神之琥珀，就在你们四个人身上。

**主题：保存与放手。** 琥珀是保存，而每一个重要人物，都是对"该留住什么、该放下什么"的不同回答。

## 一、世界结构：双树双界

```
        我们的天空（世界树的枝冠，群星是它发光的叶）
                 │
             【世界树 · 长青】        琥珀之界（我们的世界）
                 │  树根向下
    ═══════════ 根 海 ═══════════   两棵树的根在此缠结，是两界唯一的边界
                 │  树根向"下"
             【黑玉之树】              黑玉之界（另一个位面）
                 │
        它们的天空（黑玉之树的枝冠，暗紫色的天，黑色的星）
```

- **两界互为倒影**：大陆轮廓相反，住着"同样"的人，各自的命运不同。黑玉之界的文字是镜像书写的。
- **两边都管自己的树叫"长青"**，管对方的叫"黑树"。在他们眼里，我们才是黑暗那一边。
- **根海**是两棵树根须缠结的地方。挖到根海，就是在两个世界之间凿洞。
- **此失彼存**（v1.2）：两界的人是成对的。一对人命里最重的那一样东西，总是一边留着、一边放下——有时是一条命，有时是一个誓言、一片林子、一盏灯。
  - 纳坦与伊芙是最直白的一对：这一边伊芙死、纳坦活；那一边纳坦死、伊芙活。
  - 四位主角的镜影是"做了相反选择的自己"：镜中的娜希拉留在了登记处；镜中的菲德莉亚没有背誓；镜中的罗温自己卖了林子；镜中的利奥尔第一年就放走了妹妹。
  - 这条规则让纳坦的推断对了一半。伊芙在那一边确实活着，可活着的那个人，不是他失去的那一个。《根海手札》的原句是："此界之所失，彼界存之；然所存者，非所失者。"他只读到了前半句（后半句被译者裁掉了，没敢念给他听）。
  - 规则说的是"留着与放下"，不是"死者在那边活着"。利奥拉在两边都死了：这边的利奥尔留着她的魂，那边的利奥尔放了手。

## 二、年表

| 时代 | 距今 | 发生了什么 |
|---|---|---|
| **神话时代** | 三千年以前 | 神、人、野兽与各种神话生物共存。五位神各司一域 |
| **根战** | 约三千年前 | 五神想取得根部的力量，挖到根海，撞见了另一边的神。误解变成战争，两界碰撞，世界树被劈开、烧焦。几乎一切生灵灭绝 |
| **火种纪元** | 三千年间 | 幸存的一小撮人重建文明，封死根部通道，立下"不可掘根"。长青教会成立。琥珀被各家各户代代供奉 |
| **蒸汽纪元** | 最近四十年 | 纳坦·布兰特发明琥珀蒸汽机，布兰特联邦崛起，琥珀成为最值钱的商品。十二年前，他的妻子伊芙病逝；此后，大竖井越挖越深 |
| **现在** | 联邦历第四十一年 | 大竖井打穿根海，地震频发，黑玉的影子从地底涌出。纳坦亲自下到了最底层 |

**根战后留下了什么**：
- 我们这一边正要倒下的人被世界树的树脂封进**琥珀**（封住的是最后一口气，不是死者，见第三节）；另一边的，被焦黑的树干化成的**黑玉**封住。
- 五位神也在战中陨落。其中四块**神之琥珀**落在我们这一边。第五位神"炉母"跌过了边界，被黑玉裹住，化作一条沉睡在根海的**黑玉之龙**；她没有死（v1.2）。她有一小块琥珀碎片留在了这一边，四十年前被纳坦捡到。

**教会隐瞒的真相**（v1.2 改为三层，由轻到重）：长青教会三千年来一直教导人们，灾难来自"地底的黑暗"。它修剪掉了三件事：

1. **第一次掘根的，是诸神自己**。先举剑的也是我们这一边——根战是一场误会，不是一场入侵。
2. **琥珀里是活人**（见第三节）。说出来，就得有人下到根海去求炉母的火，"不可掘根"就守不住了。教会选了封印，放下了琥珀里的人，对外只说"供奉先人"。
3. **封根之门只能从里面关上，关门的人要留在门里**。第一次留下的是守根人，教会把他的名字从史书里修掉了。这一次，大修枝人给四位持珀者各写了一封"到了根海再拆"的信，四封信是同一句话："到了根海，请你留下。此事不必告知另外三位。"他不是没有说，而是对每一个人单独说了一遍：这样无论谁先到，门都有人关；而四个人凑不出一个"不"字。

## 三、琥珀与黑玉

**琥珀是什么**：世界树的眼泪。根战里每一个正要倒下的生命，世界树都没有舍得，用树脂把他停在了最后一刻。**琥珀封住的不是死者，是最后一口气**（v1.2）。世界树是第一个不肯放手的。
- 大多数琥珀里是生灵：骑士、法师、野兽、巨人。这一类叫**活珀**。里面的人是活的，醒着的时候不多，但看得见外面。
- 有的琥珀封住了一道咒术：一颗正在坠落的陨星、一阵寒潮。有的封住了一件兵器。这一类叫**空珀**。

**怎么唤醒**：把琥珀焐热，里面的生命就会醒来片刻，为持有者而战。战斗结束，它会回到琥珀里，回到那一刻，而不是死去。唤醒琥珀的温度，来自持有者体内的**火种**。火种只够让他出来站一会儿；出不出来，是里面的人自己定的。所以旧时的说法是"请"出来，不是"使唤"。

**四种对待琥珀的方式**（v1.2）：

| 做法 | 发生什么 | 谁在这么做 |
|---|---|---|
| 焐热（请） | 里面的人肯出来才出得来，战后回到那一刻 | 持珀者、旧家族 |
| 砸开 | 把人扔回最后一刻的伤里，痛得发狂 | 联邦研究站（"早醒者"） |
| 烧 | 烧掉的是那一口气，人就没了 | 联邦的琥珀蒸汽机 |
| 归还 | 把琥珀放回世界树的树脂里，他走完最后那一步 | 地下礼拜堂的石盆（游戏里的"放下一张牌"） |

**能不能活着放出来**：只有炉母的火化得开琥珀而不伤里面的人，而且只救得了被封时没有受致命伤的人。至今只有一个人这样走出来：**阿玛拉**。根战那天她是去阵前送酒的，没有受伤；四十年前，纳坦的第一台原型机里烧着炉母的碎片，把她完完整整地化了出来。

**联邦烧的是什么**：登记处的《品级凡例》规定只许烧空珀，活珀不得燃。纳坦从第一天就知道琥珀里有活人（阿玛拉是从他的机器里走出来的），这是他给自己定的规矩。伊芙死后，规矩松了：凡例添了一行附则，"大竖井三百丈以下出土者，不论品类，视同空珀"。越深的琥珀越烈，深层的钻机烧的早就是活珀。矿上挖出的琥珀一块也没有运上去，全送去了更深的地方。伊芙死于炉肺病，也就是琥珀的烟尘。

**主角为什么可以用琥珀打仗**：他们守的是旧规矩，只请，不砸不烧；想走的，在礼拜堂归还。真结局里炉母醒来，匣子里的人第一次可以自己选：肯走的走完最后一步，肯留的留下。从那以后，每一块琥珀都是自己愿意待在那儿的。

**琥珀的文化**：
- **火种纪元**：琥珀是家族的祖传圣物，供在家中神龛上。只有在生死关头，才会请出来作战。
- **蒸汽纪元**：琥珀变成了燃料和商品。旧家族变卖祖传琥珀，矿工越挖越深，因为越深的地层越古老，琥珀的力量越强。教会斥之为"焚烧先人"，但拦不住。

**黑玉**是另一边的"琥珀"。黑色、冰冷，封着另一边的战死者。靠近根海的地方，黑玉会渗进这一边，侵蚀活人和琥珀。**黑玉可以被火种焐化，净化成琥珀**。

## 四、五神

神的真名在火种纪元就失传了，人们只用尊称。

| 尊称 | 司掌 | 神之琥珀的去向 | 唤醒条件（沿用现有规则） | 为什么 |
|---|---|---|---|---|
| **群星的园丁** | 星辰、奥术。群星是世界树发光的叶，由她照料 | 娜希拉家族世代守护 | 施放 6 种不同的法术 | 她只回应博学者 |
| **执盾者** | 太阳、誓约 | 由菲德莉亚携带（原属联邦总工近卫） | 圣盾被敌人击破 4 次 | 誓言要在挨打时守住才算数 |
| **白角** | 荒野、狩猎。白色的狼狮，头生金角 | 林中村落的圣龛，由罗温携带 | 野兽猎杀敌方随从 6 次 | 他只认真正的狩猎 |
| **引路的夫人** | 月亮、亡者。她为死者引路 | 月神殿，由利奥尔携带 | 8 次阵亡、4 个不同的灵魂 | 她为每个灵魂领路，每个只领一次 |
| **炉母** | 火焰、锻造 | 本体被黑玉裹住，是根海的黑玉之龙；一块碎片是纳坦第一台引擎的核心 | 玩家不可唤醒；真结局里她自己醒来（v1.2） | 纳坦握有她，所以他只差另外四块。只有她的火能把琥珀里的人活着化出来 |

**五神的力量能打开根海，也能封住根海。谁握着五神，谁决定。** 这就是全剧的争夺核心：纳坦要开门，世界树要关门，而四块钥匙就在主角身上。

**神律（现有规则的解释）**：
- 神之琥珀只能苏醒片刻，一场战斗一次。
- 神不对凡人英雄出手。
- 神醒过一次需要长久休养，所以不能复生。
- 终战第二阶段动起来的黑玉之龙，是被黑玉裹着的炉母的"梦"，不是醒着的神，所以不违反"神不对凡人英雄出手"（v1.2）。

**为什么四位主角和神相像**：守护神之琥珀的家族，大多是当年神的凡人战友的后裔，血脉里留着神的样子。现有神与英雄立绘的相似可以成为伏笔（对照图：[img/hero-god-resemblance.jpg](img/hero-god-resemblance.jpg)）。

## 六、选角原则

这一节说明人物为什么这样设计，以后新增人物也按它来。

1. **名字要有来历**：有词源、有反讽或双关，同一文化的名字发音统一。不随手音译。
2. **每个人都有一个核心矛盾**，并且是对主题"保存与放手"的一种回答。
3. **每个人都有一个视觉钩子**：一眼能记住的物件或特征。
4. **人物之间有关系网**：主角与反派一家互相牵连，而不是各自独立的"工具人"。
5. **次要敌人用称号，不用人名**：参照杀戮尖塔的"收藏家""时间吞噬者"，"铁哨""引信"比"格伦""莉塔"好记，也更有故事。
6. **名字与立绘一致**：性别、年龄、气质都对得上。
7. **避开知名作品里同名同设定的角色**。

**一个彩蛋**：纳坦（NATAN）、伊芙（EVE）、艾达（ADA）三个名字都是回文。黑玉之界的文字是镜像书写的，只有他们一家的名字，在两个世界里读起来一模一样，就像他们在两边都是同一家人。

## 七、人物

### 四位主角（持琥珀者）

每一趟下井选一人。四人奉教会之命，分四条巷道下井，在井底会合（v1.2）：

- 路上会遇见另外三位（泵房的岔口、拆开的信、根须下的三盏灯），每次只来得及陪一个人。
- 到根海时，另外三位的火种都只剩最后一格。四封信摊开，是同一句话。三块神之琥珀交到主角手里："四块要在一个人身上才亮。"交出守了三千年的东西，是他们的放手。
- 每位持珀者有自己的两趟故事：第一趟封根，第二趟走到另一边（见第八节）。

| 主角 | 立绘 | 身份 | 视觉钩子 | 核心矛盾 | 与纳坦 |
|---|---|---|---|---|---|
| **娜希拉**（女） | 银发、藏蓝长袍、星盘 | **鉴珀师**：用星盘读出琥珀里封着的年代与生命，曾为联邦的琥珀登记处编目 | 能透视琥珀的星盘 | 她保存知识，可她编的目录，让联邦烧琥珀烧得更有效率 | 纳坦资助了她的天文台，她曾视他如父 |
| **菲德莉亚**（女） | 金发女骑士、日纹盾 | **背誓的骑士**：曾任总工近卫队长，守护纳坦一家，也是艾达的护卫 | 刮掉了联邦徽记的日盾 | 名字的意思是"忠诚"，她却背弃了誓言，为了守住一个更大的誓言 | 纳坦下令封死一座塌方的矿井以继续掘进，她当场叛离 |
| **罗温**（男） | 黑发青年、绿斗篷、长弓 | **最后的守林人**：林中村落的猎人，村子的圣龛里供着白角之琥珀 | 箭袋里插着一截花楸枝 | 他想猎杀联邦的人，可白角只认对野兽的狩猎 | 纳坦的露天矿剥光了他的森林 |
| **利奥尔**（男） | 银发、白披风、提灯 | **提灯人**：月神殿为亡者引路的人 | 他的灯里装着双胞胎妹妹利奥拉的灵魂 | 他劝所有人放手，自己却放不下妹妹 | 利奥拉死在大竖井的矿难里。他是整部作品里最像纳坦的人，也是唯一能让纳坦放手的人 |

名字的含义：
- **娜希拉**：一颗星的名字，意为"带来好消息的人"。
- **菲德莉亚**：意为"忠诚"。
- **罗温**：花楸树，民间传说里驱邪护家的树。
- **利奥尔、利奥拉**：意为"我的光"，一对只差一个字母的双胞胎名字。

### 纳坦·布兰特（最终首领）

- **称号**："点火者"。他拒绝称王，坚持让人叫他"总工程师"。
- **名字**：纳坦意为"他给予"：他给了世界火。布兰特源自"火、燃烧"。
- **出身**：穷机修工的儿子。少年时在废矿里捡到一块发烫的琥珀碎片（炉母的碎片），以此造出第一台琥珀蒸汽机。
- **崛起**：四十年间，从作坊到公司，从公司到联邦。
- **公开的面目**：进步、富足、"让每个人都用得起琥珀的光和热"。很多人真心追随他。
- **真正的伤**：妻子伊芙死于"炉肺病"，也就是工厂的煤烟与琥珀烟尘。**杀死她的，是他自己的发明。**
- **真正的目的**（v1.2 合并了两个来源）：伊芙下葬的那天夜里，他去问阿玛拉，三千年前她在根海边上看见了什么。她说了实话：对岸站着她亲手埋了的哥哥。此后他从教会封存的书库里得到《根海手札》，请译者译出了前半句"此界之所失，彼界存之"，在页边批了两个字："活着"。他认定伊芙在另一边。此后十二年，大竖井日夜不停。
- **他的规矩**（v1.2）：只烧空珀。伊芙死后，他亲手盖印，添了那行附则。
- **全程在场**（v1.2）：井壁上的铜传声管。每一幕开场，他都对这一位持珀者说话——客气、讲理，开出对方放不下的东西；到第三幕，他把教会那封信的内容直接说了出来："教会要你留在门里。我只借你的琥珀用一用。你自己算。"
- **视觉钩子**：一只永远停在伊芙去世那一刻的怀表。
- **现在**：他站在根海边，身旁是沉睡的黑玉之龙。他不恨你们，他只是在等你们把钥匙送来。
- **之后**（v1.2）：被击败后，他替主角留在门里守门（"门里面，是离她最近的地方"）。他没有放手。另一边有人敲门，用的是伊芙叫他吃饭的敲法，他开始从里面拆门。

### 纳坦的家人

- **伊芙**（这一边）：温柔、爱种花，死于炉肺病。名字意为"生命"。只存在于纳坦的怀表、日记和回忆里。
- **伊芙**（另一边）：在黑玉之界，死去的是纳坦，活下来的是她。她接过了丈夫的事业，也读到了同样的古籍，于是从另一边往下挖。从地底涌上来的"黑暗战士"，是她的人。
- **艾达**：纳坦与伊芙的女儿，天才工程师，总工近卫的现任统领。她想要回来的不是母亲，而是父亲。菲德莉亚曾是她的护卫，像她的姐姐。名字向历史上工程世家的女儿、第一位程序员艾达·洛芙莱斯致敬。

### 其他

- **阿玛拉**：铜壶酒馆的老板娘。四十年前，纳坦的第一台原型机（烧的是炉母的碎片）化开了一块琥珀，从里面走出来的就是她：**一个三千年前根战时代的人**。根战那天她是去阵前送酒的，没有受伤，所以能活着出来；她是"琥珀里封着活人"的活证据，也知道根战的真相。她的愧疚（v1.2）：伊芙下葬那晚，纳坦来问她在根海边看见了什么，她说了实话——对岸站着她亲手埋了的哥哥。她没有说的是，那个人不认得她。纳坦听成了他想听的。她开这家酒馆，每天往井里放三趟篮子，一半是为了赎罪。她承担炉石店主那样的角色：新手引导、开包时的欢呼、远征出发前的一句话。名字意为"不凋零"。
- **大修枝人**：长青教会的领袖，本名不为人知。真心想拯救世界，也真心想守住教会的秘密。"修枝"既指照料世界树，也指修剪历史。

## 八、主线

（v1.2 重写。流程与节点见 [DESCENT.md](DESCENT.md)。）

**序章**：地震。大竖井里涌出黑玉的影子。教会召集四位持珀者，每人一封"到了根海再拆"的信，分四条巷道下井。阿玛拉的酒馆是出发点。

**第一幕 · 联邦矿区**：与联邦的监工、爆破手、掘进机交手。发现矿工大量死亡，死亡名单被掩盖；估价册的附则露出联邦在烧活珀。传声管里，纳坦第一次开口。

**第二幕 · 古代地层**：火种纪元的遗迹与联邦研究站。联邦在砸开古老的琥珀；译者交出裁掉一半的残稿；得知总工程师要找的不是琥珀，而是"门"。有人提前拆了信。守根人守着封根之门：门是从里面关的。

**第三幕 · 神话战场**：根战的遗迹。传声管里，纳坦把信的内容说了出来。遇见根母、守灯之兽、艾达，以及**自己的镜影**：做了相反选择的自己。两边的教会都在派人阻止"从地底涌上来的黑暗"，第二次根战正在重演。

**终章 · 根海**：四人会合，四封信是同一句话。三块神之琥珀交到主角手里。纳坦驾驶蒸汽机甲迎战；机甲被击破后，他叫醒了黑玉之龙。

**结局**：

1. **封根**（每位持珀者的第一趟）：击败纳坦，五神亮起，门合到只剩一道缝。主角照信上写的走向门里，被纳坦拦住："这口井是我挖的。门，我来关。"他留在了门里。每位主角有自己的一句收尾（利奥尔在门缝前放走了妹妹）。
   - 这是一个会失效的结局：封印只封住了一边，守门的又是最想开门的那个人。阿玛拉听见井底有人从另一边敲门。
2. **镜中人**（同一位持珀者封过根之后再下井）：整趟的文字换成第二遍的版本——传声管里只有敲门声，守根人重新站了起来（"只关一边，守不住"），艾达守着门的图纸，纳坦在门里拆螺栓。再次击败他，主角侧身穿过门缝，走进黑玉之界，在玻璃温室里见到另一边的伊芙。她和纳坦隔着根海相见，读完了被裁掉的后半句：留下来的，不是失去的那一个。两人各守门的一面。**爱打开的门，由爱来关上。**
   - 为什么是他们：门有两面，只关一边守不住；能守住的，是两个终于不再想过去的人。
   - 炉母自己醒来。她的火漫过主角的琥珀匣，里面的人第一次自己选：肯走的走完最后一步，肯留的留下。
   - 两个世界之间留下了一扇可以敲的门，这是未来扩展包去往另一边的入口。

**解锁条件**（v1.2 统一）：真结局按持珀者各自计算，同一位封过一次根，下一趟就会走到第九层。不再要求四人各通关一次。

**揭示顺序**：

| 进度 | 揭开什么 |
|---|---|
| 第一幕 | 联邦在掩盖矿难；深层在烧活珀 |
| 第二幕 | 总工程师要找的是"门"；琥珀封的是最后一口气；门只能从里面关 |
| 第三幕 | 黑暗战士是另一个世界的人；此失彼存；信上要你留下 |
| 第一次封根 | 四封信；伊芙；纳坦留在了门里 |
| 封根之后 | 阿玛拉的来历与她说过的那句实话；门关不住 |
| 真结局 | 手札的后半句；另一边的伊芙；炉母的火 |

## 十、敌人体系

**战斗形式**：保留双方对称出牌（双方都有英雄、法力、手牌、随从），这是现有规则、AI 和 3D 战场的核心。

**做法参照炉石"地下城冒险"**：每个对手由称号、立绘、专属英雄技能、一条被动规则、一套主题卡组（现有卡池加 1–3 张专属卡）构成。

**借鉴杀戮尖塔的"意图预告"**：精英与首领的大招提前一回合显示，玩家可以提前应对。

## 十一、卡牌在世界里是什么

| 规则 | 解释 |
|---|---|
| 卡牌 | 一块琥珀，里面封着一个远古生命、一道咒术或一件兵器 |
| 牌组 | 随身的琥珀匣 |
| 法力（每回合 +1，上限 10） | 持有者的**火种**之温：体温一点点升起，最多焐热十分 |
| 以太硬币 → **琥珀碎片** | 一小片琥珀，多给一分温度 |
| 召唤后要等一回合 | 琥珀复苏需要时间 |
| 随从阵亡，下一场又能用 | 它退回了琥珀，而不是死去 |
| 衍生物不留灵魂、不计入仪式 | 它们是琥珀力量的投影，不是生命 |
| 传说卡只能带一张 | 远古英雄的琥珀独一无二 |
| 神的契约不进牌组 | 神之琥珀由持有者贴身携带，只能靠仪式唤醒 |
| 沉默 | 把它的力量重新封回琥珀里 |
| 冻结 | 像被封进琥珀一样凝住 |
| 奥秘 | 暗藏的琥珀，条件满足时自己苏醒 |
| 亡灵 | 被黑玉侵蚀的生命 |
| 龙 | 炉母的余裔 |
| 构装体（石像、泰坦） | 联邦的蒸汽傀儡与发条兵 |
| 遗物 | 根战遗留的器物 |
| 金币、买牌、删牌 | 联邦马克，在补给站买卖琥珀 |
| 练习对战 | 铜壶酒馆里用仿制琥珀打的牌局，输了只输一杯酒 |

**现有传说卡的身份**：
- **逐日者·索拉**：根战中执盾者麾下的骑士。
- **星陨女王·妮克丝**：根战时代的星之女王。
- **白霜之王**：根战英雄，战后把自己冻在井中守根，就是"守根人"。
- **终焰·阿什拉**：改名"炉母的余烬"，就是纳坦引擎的核心碎片。
