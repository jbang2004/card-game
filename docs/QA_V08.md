# v0.8 本轮验收

## 交付

压缩包内 207 个文件已全部落盘，没有缺失。保留 56 张卡牌图、来源素材表、建筑图层、加工工具和交接文档。纯规则引擎与卡牌数据仍通过原始 SHA-256 一致性检查。

- 网页入口：`http://127.0.0.1:8000/dist/`
- 离线单文件：根目录 `index.html`
- 机器报告：`artifacts/qa/results.json`、`tests/windborne/suite-status.json`
- 当前构建信息：`dist/build-manifest.json`

## 修复与设计

1. 桌面六至十张手牌原本互相遮住攻血。现在由单独的布局函数分配完整槽位，将属性标记收进卡牌边界。悬停不再把卡牌放大到英雄上方，独立预览承担细节阅读。
2. 结束回合与法力统一放入右侧操作区，牌库移出手牌范围。
3. 桌面提示原本覆盖自己的英雄，现使用场景侧边空闲区。
4. 小横屏的敌方法力原本与己方英雄重叠，自己的法力也与结束回合重叠。现在移到手牌上方；紧凑横屏保留数值而不堆叠十颗法力装饰。
5. 手机通知原本盖住敌方随从。现在明确预留通知带，并重新计算战场高度。320 像素竖屏的手牌标题也避免了挤成竖排。
6. 默认不再同时加载旧 3D 几何与手绘棋盘。完整手绘 Canvas 世界及七系战斗演出独立运行，无外部 CDN 请求；原 3D 分支作为显式开发预览保留。
7. 卡牌、焦点与数值依然动态渲染，保留用户已确认原画。本轮没有重新生图，也没有把代码绘制角色混入现有卡池。

## 验证覆盖

**规则／素材：45 项。** 包括 150 局随机完整对战的状态不变量、AI 合法动作、伤害、圣盾、嘲讽、武器、亡语、复生、抽牌上限和严格素材映射。

**既有浏览器：67 项。** 31 项触屏／桌面流程、5 项补充回归、17 项动漫资产集成、14 项场景集成。使用明确的内存存储适配器、屏蔽外部网络的离线单文件路径。

**新增真实 HTTP 端到端：14 项。** 使用拆分构建：

- 全部 56 张卡图及 9 张环境素材真实解码、没有 HTTP 错误和外部依赖请求；实际点击施法、攻击、召唤、结束回合及 AI。
- 正式圣卫战役在真实 localStorage 中保存并跨刷新恢复，设置与日夜选择保留；试玩和返回首页不覆盖正式存档。
- 11 种桌面／触屏配置，双方各 7 个随从、10 张手牌。检查视口边界、手牌之间的重叠、攻血中心的实际命中对象，以及通知／法力与角色、操作按钮的相交。
- 手机点牌阅读不消耗法力；确认后施法，并在动画途中切换横屏，同局结果保留、无重复扣费或残留输入锁。

测试包含真实浏览器操作和受控满场场景。满场截图是布局压力场景，不冒充自然完成的战役。

系统 Chrome 的一轮自动测试在退出阶段停滞，改用机器已有的 Chromium headless shell 152 完成有退出码的正式回归。人工视觉检查仍在本机 Chrome 中进行。测试运行可通过 `CHROMIUM_PATH` 指定浏览器；不需要修改系统浏览器设置。
