# UI 与装饰定位排查 · 2026-09-09

本轮在既有 v0.14 游戏上修复五类布局问题；仅修改 components 层 CSS，未更改规则、角色素材或发布线上。

## 确认的问题与修复

| 问题 | 根因与修改 |
| --- | --- |
| 桌面英雄名牌向右突出 | 旧 tavern 的 `width:108%` 与 premium 的左右 `4%` 同时生效，1600px 截图中名牌右沿 889.27，头像右沿 872。设 `width:auto`，由左右内缩决定宽度。 |
| 收藏搜索框与关闭按钮重叠 | 关闭按钮改为内缩 20px、44px 大小后，收藏标题区保留旧的较小留白；统一预留 64px；横屏标题行增至 54px、页签同步下移 18px，避免关闭按钮下沿覆盖费用筛选。 |
| 竖屏法力水晶位置偏高 | 手机 12px 水晶继承桌面 24px 高、100% 宽的容器，未在条内居中。给数值和水晶各自自然宽度，水晶条高 12px，并垂直居中。 |
| 结束回合内描边与外框不一致 | 外框已改为不对称圆角，伪元素仍沿用 7px 等圆角。按内缩距离设置对应内圆角，装饰不接收指针。 |
| 横屏单张契约插画缩成窄条 | 单张契约的 30% 网格列又叠加图片自身 32% 宽度，插画只占整卡约 9.6%。横屏统一网格布局，图片填满其网格列。 |

## 用户截图反馈：头像装饰清理

用户指出战场头像顶部的多边形金片突兀。移除 `ui.js` 中双方英雄的 `hero-carving` 空装饰节点及 components 中重新启用它的规则；头像恢复连续拱形轮廓。同步收细头像边框，去掉重复外金环，手机采用 2px 边框和内距，桌面采用 3px 边框。头像名牌、血量、护甲及交互状态保持原有 DOM。

复查首页徽章、弹窗器物边框、收藏书脊、英雄选择桂冠和契约环，未发现相同的多边形贴片问题，未盲目替换这些素材。

本次装饰清理验证：构建与 116 项单元测试通过；8 种尺寸定位回归最终全部通过，UI polish 的 5 项交互回归通过。首轮浏览器检查恰逢再次构建，390px 页面初始化超时；稳定构建后重新运行全部 8 个尺寸通过。截图 `artifacts/ui-alignment/clean-hero-frame.png` 与 `clean-320-battle.png` 已人工复核。
