# v0.10 — 字体、配色和卡图容器重构

2026-09-07，针对用户提供的三张截图。

问题根因是旧版桌面、手机、稀有度与拱形卡框规则拥有不同优先级，新增材质没有可靠覆盖它们。

本次在模板中明确声明 `legacy → layout → theme → components` 四个 CSS 层级。历史样式保留基础兼容；新组件通过层级获得一致的最终控制权，不再靠堆叠选择器覆盖。

- `src/presentation/components.css` 统一深木色底、浅米色正文、金色主按钮和棕色次按钮。手机响应规则只调整尺寸，不改变主题颜色。
- 正文使用系统无衬线字体，去掉模糊重阴影；卡面文字与数值使用容器宽度单位随实际卡宽调整，保留小手牌的紧凑规则。
- 全部卡牌共享唯一的矩形图片窗口，内框负责圆角裁切。移除图片额外缩放、旧拱形轮廓和伪元素纸面；费用和攻血是独立外层组件。

## 验证

18 项 Playwright 端到端测试通过，包括原有对局、存档、触屏旋转、11 种满场/满手牌布局与数值容纳检查，以及新增设计契约：

- 1600×940 桌面、390×844 竖屏、844×390 横屏的大厅、主按钮、次按钮实际背景与文字颜色相等。
- 大厅说明、介绍、眉题文本对比度均达到 4.5:1。
- 48 张收藏卡图的 DOM 边界与图片窗口吻合，不存在负偏移或图片变换越过窗口的旧结构。

45 项 Node 规则/素材测试与 67 项原 Python 浏览器检查通过。最后的收藏标签配色调整另复跑设计契约测试通过。已人工查看实际 in-app 浏览器的大厅与收藏页，以及桌面和手机对战截图。
