# 全角色动态上线：体积与性能（2026-09-08）

## 基准与方法

主基准为 Sites 当前公开版本 3 的源码 `b06640dc72c2098c140fe9d0454a865eb7260324`，该版没有人物分层动态。从该提交独立重建，与本次 35 个上场角色动态的 `dist/` 比较。不是把最近的六角色演示误当作线上旧版。

两版均使用本机 Chrome、Playwright、同一 HTTP 服务方式。固定 14 个不同场上角色和 9 张手牌，等待加载稳定后采样 5 秒；桌面 1600×940，触控模拟 844×390。资源字节为 ResourceTiming 的 encodedBodySize 总和，不含主 HTML、HTTP 头，且本地服务未开启压缩；不是 CDN 实际流量。首页和战场均未发生页面脚本错误。

## 稳态性能与内存

| 指标 | 桌面原版 → 新版 | 触控布局模拟原版 → 新版 |
|---|---|---|
| RAF 帧率 | 60.00 → 60.00 FPS | 60.00 → 60.00 FPS |
| 帧间隔 p95 | 16.8 → 16.7 ms | 16.7 → 16.7 ms |
| 主线程忙碌时间占比 | 1.83% → 3.92%（+2.09 个百分点） | 1.75% → 4.08%（+2.33 个百分点） |
| 人物图层估算解码内存 | 0 → 22.5 MiB | 0 → 12.75 MiB |
| 人物 Canvas 像素缓冲估算 | 0 → 0.84 MiB | 0 → 0.14 MiB |
| 活跃人物动画数 | 0 → 12 | 0 → 6 |
| 手牌人物 Canvas 数 | 0 → 0 | 0 → 0 |

主线程占比由 CDP TaskDuration 增量除以采样时间得到，单次短样本会波动；不能视为整机 CPU、GPU 或耗电百分比，也不能据此保证低端手机 60 FPS。触控结果仍由桌面 Chrome 模拟，不是实体手机验收。解码内存按宽×高×4 估算，不含浏览器可能额外保留的 GPU 副本。

运行时共用一个 RAF，桌面/触控最多同时播放 12/6 个角色，缓存最多 16/8 个角色；手牌静态，冻结角色停止重绘，减少动态设置可回退静态。按当前角色清单，缓存图层理论峰值约 27.75/15.75 MiB，此外还有 Canvas 及浏览器开销。无需把全部 35 角色同时解码。

另以新渲染器限制为原六角色作控制组：本场景解码内存 6 MiB、约 60 FPS；全角色增加的主要是覆盖范围和贴图内存。该控制组不是历史六角色版本，不能用单次 CPU 差异评价旧实现优劣。

发布前完整回归：68 项 Node 规则/素材测试、4 项制作工具测试、41 项 Playwright 测试通过。原始本地性能报告保存在忽略目录 `artifacts/performance/comparison.json`。
