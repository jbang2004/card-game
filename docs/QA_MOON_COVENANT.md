# 月影神契验收 · 2026-09-08

验证对象为 v0.13.0 本地源码和同源构建的 dist / 离线单文件，公开站点未更新。内容共 73 张卡图、41 个动态随从、4 位英雄、8 套预设、6 位首领。

## 玩法筛查

本轮完成 560 局自动对局：三轮各 48 局调整筛查、192 局留出种子验证、224 局全预设/首领矩阵。没有将模拟称为真人胜率，也没有实体手机测试。

契约专项采用同一公开信息 AI、固定搜索节点预算，每个种子配对先手和后手。前六套预设分别作为对手，每套新预设初期 24 局，留出阶段 96 局。逐配对汇总见 [moon-balance-summary.json](moon-balance-summary.json)。

| 阶段 | 搜索预算 | 月影神契 | 契兽群猎 |
| --- | ---: | ---: | ---: |
| 初始数值 | 100 | 10/24 | 10/24 |
| 修正复生估值 | 100 | 7/24 | 9/24 |
| 引路人/契鹿加强，狼王升费 | 100 | 10/24 | 9/24 |
| 留出种子（offset 20） | 160 | 42/96 | 41/96 |

留出阶段月影神契胜率 43.75%，契兽群猎 42.71%；平均结束于第 14.2 / 11.1 个玩家回合。神祇分别登场 78 / 51 局，两者登场回合中位数均为 10。契兽使用率很高，表明当前 AI 倾向于在中期兑现资源；对旧游侠仍偏弱。增加预算会改变策略，因此不能把留出阶段与前期差值全部归因于数值改动。

全矩阵为八套预设对八套预设共 128 局，以及八套预设对六位首领共 96 局，首领测试不携带遗物。第六关每套预设两局中分别获胜 0、1、0、2、1、1、1、1 局。没有不终止对局或无效状态报告；此矩阵不等于带遗物的完整六关通关率。

## 规则与浏览器

`npm run test:release` 最终完整回归通过：106 项 Node 单测、4 项制作工具测试、87 项 Playwright 测试（约 4.1 分钟）。`python3 tools/characters.py --check` 与 `git diff --check` 通过。手册规则与版本标题收尾后重新构建，契约和 UI/UX 定向回归 15 项全部通过。完整浏览器结果保存在本地 `artifacts/qa/moon-release-results.json`。

规则覆盖目标校验和拒绝动作原子性、牺牲亡语、印记去重、变形/沉默、顺序支付、场地容量、一次性契约、神祇冲锋限制、不能复生、存档恢复与损坏拒绝、AI 无副作用，以及契约不能从手牌/存档牌库绕过支付。

浏览器覆盖 1600×940 桌面、390×844 竖屏和 844×390 横屏契约面板与降临；命名卡组配置持久化、刷新后一次性限制、减少动态效果；完整练习对局通过真实按钮执行动作。全角色分页测试验证 41 个随从均能绘制、运动、冻结停绘及解冻恢复；手牌没有动态画布。

首轮完整回归发现两项旧测试假设失效：写死六套预设，以及自动点击器没有 contract 动作。已按当前内容目录和真实契约按钮修正；不通过放宽终局断言掩盖问题。
