# 页面布局重构 · 2026-09-09

## 问题与根因

旧弹窗同时受桌面舞台缩放、手机绝对定位、通用滚动容器和各页面局部尺寸控制。装饰框的可见厚度没有成为内容布局的约束；窗口高度不足时，标题、内容、按钮继续纵向竞争高度，按钮贴框、配置区被压缩。仅增加某个分辨率的偏移会把问题转移到其他尺寸。

## 新布局契约

- `src/presentation/dialog-layout.js` 是弹窗内容区唯一的挂载、尺寸与滚动入口；`ui.js` 只负责内容和动作绑定。
- 弹窗挂载于 `body`，使用真实视口 CSS 像素，脱离游戏舞台缩放。战场仍使用已有独立的桌面/触屏布局。
- `dialog-layout.css` 在 components 层接管弹窗几何；胡桃木、古金、装饰图仍来自现有主题。装饰边框厚度 `--rim` 与留白 `--air` 相加得到内容安全内距。
- 外层适应 `100dvh` 和设备 safe-area，标题、内容、操作区各有明确空间。关闭与主要确认按钮至少 44 CSS px。矮窗口把操作区转为侧栏，避免继续压缩正文。
- 内容采用单一纵向滚动面；不以 `overflow:hidden` 掩盖正文，也不使用横向分页或 CSS 多栏拆文。按钮和配置行固定在滚动内容之外，滚动提示只在确有溢出时出现。
- 卡牌与牌组使用保持卡牌宽高比的响应式网格，列数随容器宽度变化；所有卡牌、牌组和长文本连续排列，避免末页孤项、分页残影和横向遮挡。
- 收藏在宽容器中显示卡牌与牌组两栏，窄容器用标签页。布局条件针对容器容量，并非手机型号或固定横竖屏坐标。
- 矮屏把筛选按钮组换成类型/费用下拉框；配置步骤完成后返回牌组保存操作。校验提示与配置标题同排，避免错误提示挤掉操作内容。
- 缩小的收藏卡片保留卡名、费用与攻血，完整规则使用明确的“详情”入口；详情可以返回原收藏页，筛选与草稿不丢失。长按也进入同一个详情界面。
- `ResizeObserver`、内容变更与图片加载共同触发单帧重排。保留真实输入节点、事件与值，不在 resize 时重新创建对话框；关闭时清理监听。

## 覆盖页面

统一入口覆盖英雄选择、收藏/牌组、设置、地图、规则、契约、奖励、换牌、结果、确认框、触屏详情/手牌/菜单/日志、画廊和特效实验室。实验室保留专用舞台布局，确保真实特效起终点与操作区域一致。

本次还修复奖励卡片的图文碰撞，并将英雄选项调整为左图右文的横向卡片，去掉不适合该结构的顶部装饰。

## 2026-09-09 弹窗密度与顶栏图标复修

- 统一分页机制不变，弹窗外框改按任务分为确认、详情、标准、选择与工作区五档；收藏仍使用 1400px 宽工作区。常规桌面下确认框为 620×360、详情为 720×580、设置与结果等标准框为 900×640，不再把短内容强制扩成 1180×850。
- 窄屏继续受真实视口和安全边距约束；矮屏侧栏操作区现在只由视口高度触发，不会因为弹窗主动缩小而误触发。
- PC 顶栏声音、全屏、设置按钮统一为 32×32 图标盒和 18×18 块级内联 SVG，清除原生按钮内边距导致的 1.5px 横向偏移。声音/静音路径也收回 24×24 viewBox，并与其几何中心对齐。
- 新增 `dialog-sizing.spec.cjs` 验证语义尺寸、框体居中、SVG/按钮圆心和路径边界。最终 `npm run test:release` 通过规则/应用 116 项、美术 6 项、浏览器 138 项，零失败、零跳过；未发布线上。

## 2026-09-09 移动端孤页复修

- 固定数量的触屏控制页新增 `fit` 页面策略。设置与掌中菜单会在一屏内响应式重排，不产生只剩一个按钮的末页，也不引入纵向滚动。
- 设置页保留完整尺寸的开关与滑杆，移动端收起已由标签表达的辅助说明；菜单根据宽度自动调整列数，浅横屏收起重复操作提示。
- 地图、玩法手册、收藏、手牌与契约属于长内容或数量可变内容，统一采用纵向滚动，避免为了塞入单屏而把文字和卡面压到不可读。
- 新增 `mobile-dialog-fit.spec.cjs` 覆盖 390×844、320×568、844×390、568×320，验证单页、零双向溢出、控件完整可见及按钮不小于 44px；`npm run test:release` 最终通过规则/应用 116 项、素材 6 项、浏览器 143 项。

## 2026-09-09 分页操作与箭头复修

- 新增通用 `data-dialog-action` 约束：内容可以在语义位置声明主要操作，但弹窗挂载时会移动同一个真实节点到分页外的固定操作栏，保留状态、事件与无障碍信息。诸神契约是首个接入页面。
- 契约移动端改为不可拆分的紧凑账册卡；窄竖屏减少纯装饰图片，浅横屏保留名称、费用、实时进度与固定操作。单契约不再产生空白分页，三契约的三个唤醒按钮在横竖屏均同时可见。
- 分页按钮不再使用受系统字体影响的 `‹` / `›` 字符，改为 24×24 对称坐标系中的编码 SVG；按钮统一为 44×44，图形渲染为 18×18，按钮中心、SVG 中心和路径几何中心完全一致。
- 回归检查覆盖单/三契约、320×568 与 568×320 极限尺寸、操作节点不进入分页容器，以及分页 SVG 的按钮尺寸、渲染尺寸和几何中心。
- 最终 `npm run test:release` 通过规则/应用 116 项、素材 6 项、浏览器 146 项，零失败；未发布线上。

## 2026-09-09 连续滚动收束

- 移除运行时分页状态、分页导航、横向页面测量、CSS 多栏流动及相关断点变量；`folio-viewport` 是唯一正文滚动容器。
- 收藏卡墙、牌组列表和右侧牌组编辑区都改为独立的纵向滚动面，并在底部只显示有实际溢出时的滚动提示。
- 移除旧 `modal-scroll` 的滚动和移动端结果网格职责；保留这个类名仅作为动态设置内容的语义包裹层，避免破坏现有节点和事件绑定。
