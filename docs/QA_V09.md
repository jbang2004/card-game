# v0.9 鎏金酒馆 · 视觉重构

2026-09-07。针对用户提供的背景切边、生命与费用数字超界截图，重新制作场景与 UI。

## 实现

- 单张连续酒馆原画替换建筑蒙版、棋盘和绿底的拼接。桌面不再绘制旧建筑裁片；小屏棋盘依原生视口布局独立适配。
- 新材质统一英雄框、卡框、卡背、随从、法力、回合按钮、提示、英雄选择、收藏和设置面板。保留 56 张已确认的角色原画。
- 数值不使用多边形裁切；独立的圆形徽章、内边距、字体行盒和紧凑随从规则容纳两位数字。
- 场景渲染从 500 行简化到153 行，保留缓存、昼夜、互动和手机调用接口。环境与规则层保持分离，存档格式不变。
- `premium-assets.js` 可从审核后的 WebP 重建。新 PNG 原图、运行图片和完整生图提示词见 `assets/premium/README.md`；由内置 imagegen 生成。

## 验证

- 45 项 Node 规则与素材测试通过，含 150 场随机完整对局。
- 17 项 Playwright 端到端测试通过：真实出牌/攻击/AI、跨刷新存档、触屏选牌与旋转、11 种视口的 7 对 7 满场与 10 张手牌、桌面与小屏数字边界。
- 新数字测试通过 DOM Range 测量实际字形边界，分别代入 1、2、3、10、30；它实际捕获并推动修复了小屏随从徽章缩小后容不下两位数字的问题。
- 实机截图检查桌面对局与英雄选择，另检查 320×568 竖屏、568×320 横屏截图。截图在 `artifacts/qa/premium-*.png`。
- 原 Python 浏览器回归共 67 项检查通过（场景套件按新版本契约更新后单独重跑）。结果见 `tests/windborne/suite-status.json` 与对应日志。

本轮改善的是本地单人游戏的视觉与实现；未新增联网对战、服务器、商业素材管线或实体手机/GPU 验收。不存在“已达到商业大作全部品质”的自动化证明。
